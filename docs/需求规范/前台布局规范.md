# 前台布局规范

- 统一顶部栏由 AppLayout 占据实际布局高度，页面不得再添加用于避让顶部栏的空白占位块。
- 图像页保留生图、融图、图片翻译子标签；页面外层提供顶部间距，标签栏不再重复添加顶部间距。
- 影像、画布、资产、收藏和团队页不得用空白块对齐其他页面的标签栏。
- 新增或修改公共顶部栏时，检查全部子页面的占位和间距，避免只修复单个页面。
- 首页搜索只在首页展示，同一组搜索和会员等公共入口不在页面内部重复渲染。
- 顶部搜索框以外层背景变化表示焦点，不给内部输入框添加描边；空输入框获得焦点后仍保留提示文字。
- “我的”入口放在顶部栏“会员中心”右侧，登录入口和账户菜单跟随该按钮展开。
- 顶部文字 logo 始终显示；侧栏收起只影响左侧导航内容，不隐藏品牌文字。
