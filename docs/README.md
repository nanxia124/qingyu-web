## 每个文档固定结构

开头是三小节大白话（用 ### 小标题，字号小不抢眼）：
- **这是什么**——一句话说清楚
- **用户怎么用**——用户看到什么、点什么
- **现在长什么样**——已经做了什么、还差什么

下面是原来的详细内容，保留给开发和 AI。技术细节用斜体小字，给 AI 对照代码用。
