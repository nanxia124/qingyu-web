# AI 对话

### 这是什么

网站里的聊天页面，跟一个 AI 多轮对话。你问一句它答一句，边想边出字，聊过的内容自动存下来，换设备也能接着聊。可以调它的性格、让它联网查资料、把聊过的内容导出成文件或者分享给别人看。

### 用户怎么用

1. 打开 `/chat` 页面，中间是输入框，左上角有"新建对话"按钮，左边一竖列是历史对话列表

2. 在输入框里打字，按回车发送，AI 一个字一个字往外蹦（流式输出），不用干等

3. 觉得它说得太慢或者不想等了，点一下"停止"按钮，它就停下来，已经说出来的内容保留

4. 对这次回答不满意，点"重新生成"，它换个说法再来一遍

5. 左边历史列表里能看到你所有聊过的对话，按时间倒序排，点哪个就切到哪个；每个对话自动有个标题，也能手动改

6. 输入框上面可以选角色人格（比如代码助手、写作搭档）、调创造性高低、开联网搜索，这些设置对当前对话生效

7. 聊长了以后，顶部会自动出现一段"前文摘要"，不用往上翻就能想起前面聊了啥

8. 想把对话存下来，点"导出"下载成 Markdown 文件；想分享给别人，点"分享"生成一个只读链接发给朋友

### 现在长什么样

还没开始做真对话。当前页面只是个 UI 壳子：长得像聊天框，但点"发送"只会 0.4 秒后弹一句固定文案"服务待开通"，对话存在浏览器内存里，一刷新全没。没有后端接口、没有流式输出、没有历史保存、没有 Markdown 渲染。下一步：先把后端对话接口和流式输出打通，再做历史列表，最后加角色/温度/联网搜索这些增强。

### 业务规则

1. **<span style="font-size:18px;color:#fff">按回车发送消息，Shift+回车换行，跟微信一样。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">textarea onKeyDown：e.key==='Enter' && !e.shiftKey 时 preventDefault 并触发 send()；输入框为空或正在发送时发送按钮禁用</span>

2. **<span style="font-size:18px;color:#fff">AI 回复是一个字一个字蹦出来的，不是等半天一次性出来。发送后立刻开始出字，打字机效果。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">后端 POST /api/chat/completions 返回 SSE 流（text/event-stream），前端用 fetch + ReadableStream 逐块读取 delta，追加到当前 assistant 消息的 content；每收到一块就触发一次 React 重渲染</span>

3. **<span style="font-size:18px;color:#fff">AI 正在说话的时候，发送按钮变成"停止"按钮，点一下它就闭嘴，已经说出来的字保留不丢。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">sending 状态时发送按钮位置切换为 Square 图标（停止），点击调用 controller.abort() 中断 SSE 流；中断后把已收到的内容作为完整 assistant 消息落库，status='aborted'</span>

4. **<span style="font-size:18px;color:#fff">AI 回复完觉得不满意，下面有个"重新生成"按钮，点一下它删掉这次回复，重新答一遍，前面的对话上下文还在。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">重新生成时删除最后一条 assistant 消息（或标记 regenerate），把最后一条 user 消息重新发给后端，temperature/模型等参数沿用当前对话设置；前端禁用连续点，生成中按钮转 loading</span>

5. **<span style="font-size:18px;color:#fff">AI 回复里的代码块要带语法高亮，列表、加粗、标题、表格都要正常渲染，不能直接显示一堆星号和井号。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">用 react-markdown + remark-gfm 渲染，代码块用 react-syntax-highlighter（OneDark 主题，跟暗色背景配），流式输出过程中也实时渲染，不是等结束才渲染</span>

6. **<span style="font-size:18px;color:#fff">多轮对话有记忆：你后面问的问题，它记得前面聊过什么，不用你每次重新交代背景。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">每次发请求时把当前对话的全部历史消息（role+content）作为 messages 数组传给后端；后端按对话 id 从数据库读历史，截断到模型上下文窗口上限（默认最近 20 轮，超出走自动摘要）</span>

7. **<span style="font-size:18px;color:#fff">左边一竖列是历史对话列表，按最近聊过的时间倒序排，当前正在聊的那条高亮。刷新页面或者关掉浏览器再打开，对话还在。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">左侧边栏 260px，调接口 GET /api/chat/conversations 返回列表（id/title/updated_at），按 updated_at desc；点击切换对话时 GET /api/chat/conversations/:id/messages 拉取消息；登录后才显示历史，未登录引导登录</span>

8. **<span style="font-size:18px;color:#fff">左上角有个"新建对话"按钮，点一下开一个空白对话，之前的对话不会丢，在左边列表里。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">新建对话不立即建数据库记录，等用户发第一条消息时才 POST /api/chat/conversations 创建（避免一堆空对话）；新建后清空当前消息列表，回到空状态欢迎页</span>

9. **<span style="font-size:18px;color:#fff">历史列表里每条对话 hover 一下出现两个小按钮：重命名和删除。删除必须弹确认框，不能手滑删了就没了。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">hover 显示 Pencil（重命名）和 Trash2（删除）图标；删除用 antd Modal.confirm，文案"确定删除这个对话吗？此操作不可恢复"；确认后 DELETE /api/chat/conversations/:id，成功后从列表移除，toast"已删除"</span>

10. **<span style="font-size:18px;color:#fff">重命名对话时双击标题或者点铅笔图标，弹个小输入框直接改，回车保存。</span>**<br>
    <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">行内编辑，双击标题变成 input，Enter 或失焦保存，Esc 取消；保存调 PATCH /api/chat/conversations/:id {title}，toast 成功/失败</span>

11. **<span style="font-size:18px;color:#fff">你发完第一条消息以后，系统自动让 AI 给这个对话起个短标题（不超过 20 个字），不用你自己想。</span>**<br>
    <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">第一条 assistant 消息流式结束后，后端异步触发一个轻量调用：把用户第一句话发给模型，要求用不超过 20 字总结成对话标题；拿到结果后 PATCH 更新 conversation.title；失败不阻塞主流程，标题 fallback 成"未命名对话"+时间</span>

12. **<span style="font-size:18px;color:#fff">聊了很多轮以后（超过 20 轮或者消息总 token 超过模型窗口的 70%），顶部自动出现一段小灰字"前文摘要"，点一下展开看全文，不想看可以收起。这样再长的对话也不会把上下文撑爆。</span>**<br>
    <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">后端在每次发请求前判断上下文 token 数，超过阈值时自动触发 summarization：把最早的 N 轮消息发给模型生成摘要，存到 conversation.summary；后续请求用摘要替换被压缩的早期消息；前端在消息列表顶部显示"📋 前文摘要"折叠条，点击展开完整摘要</span>

13. **<span style="font-size:18px;color:#fff">AI 回复完以后，下面会自动冒出来 2~3 个浅蓝色小药丸按钮，是它猜你接下来可能想问的问题。点一下就直接当作你的下一条消息发出去，不用自己打字。</span>**<br>
    <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">主回复结束后，SSE 流最后一个 event 类型是 recommendations，返回 2~3 条建议问题；前端渲染成可点击的 Chip 按钮组，点击后把该问题作为新 user 消息发送；用户手动输入新内容后推荐按钮消失；推荐按钮只在最新一条 assistant 消息下面显示</span>

14. **<span style="font-size:18px;color:#fff">输入框上面有个角色人格选择器，预设几个常用角色：默认（无角色）、代码助手、写作搭档、翻译官、面试模拟。选了以后 AI 就按那个角色的语气和专长说话。</span>**<br>
    <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">预设角色存在前端常量数组里，每个角色对应一段 system prompt（如代码助手："你是一个资深全栈工程师，回答问题给出可运行代码和解释"）；选择器是下拉菜单或 Chip 组，默认"默认"；选中后写在 conversation.system_prompt 字段，后续每轮请求自动带上</span>

15. **<span style="font-size:18px;color:#fff">输入框旁边有个"创造性"滑块，从"严谨保守"滑到"天马行空"。往左滑 AI 回答更稳更确定，往右滑更有想象力但可能胡扯。</span>**<br>
    <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">滑块范围 0~1，步长 0.1，默认 0.7；0.2=严谨保守 / 0.5=平衡 / 0.9=天马行空；映射到 LLM API 的 temperature 参数；滑块旁边实时显示当前档位名称；设置保存在对话级别，可随时调整</span>

16. **<span style="font-size:18px;color:#fff">输入框旁边有个"联网搜索"开关，默认关。打开以后 AI 回答前会先搜网上的最新资料，回答里会带引用来源。适合问新闻、实时信息、最近发布的东西。</span>**<br>
    <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">开关打开后请求带 web_search=true；后端收到后先调用搜索 API（Bing/SerpAPI）拿 5~10 条结果，把摘要拼进 context 再调大模型；流式回复末尾追加"参考来源"区块，列出标题+链接；未接入搜索的模型自动禁用开关并提示"当前模型不支持联网"</span>

17. **<span style="font-size:18px;color:#fff">消息很长、你又滚到下面看别的东西的时候，右下角会冒出来一个"↓"按钮，点一下平滑滚到最新一条消息。你已经在底部了它就自动藏起来。</span>**<br>

18. **<span style="font-size:18px;color:#fff">发送失败的时候（网络断了、后端报错），你那条消息旁边不会消失，而是标红，下面有个"重试"按钮，点一下重新发，不用重打一遍字。</span>**<br>

### 出问题怎么办

* 发消息没反应 → 先看网络是不是断了，断了消息会标红，点重试；网络正常还不行就刷新页面
* AI 回复到一半卡住了 → 点"停止"按钮停掉，再点"重新生成"
* 对话历史不见了 → 确认是不是登录了同一个账号，未登录的对话只存在本地浏览器
* 积分不够发不了消息 → 点提示里的"去充值"跳转到钱包页，或者等明天免费额度刷新
* 分享链接打不开 → 可能是原作者收回了分享，或者对话被删除了

### 花多少钱

按 token 计费：输入和输出分别按模型定价扣积分，跟生图一样从余额里扣。具体每个模型多少钱，在管理后台的模型目录里配，前端不写死。未登录状态可以体验但不持久化。
