# 聊天界面体验优化

### 这是什么

把 `/chat` 这个聊天页从现在的简陋门面，打磨成跟主流 AI 聊天产品一样顺手的样子：每条消息有头像、有时间、气泡带小尾巴，AI 一个字一个字往外蹦，左边能翻以前的对话，嫌打扰还能一键专注。顺便把发消息、复制、拖文件这些小动作也都做舒服。

### 现在长什么样

网页端对话服务还没接进来，现在的 `/chat` 是个**纯前端门面**：

- 你发的消息存在浏览器内存里，刷新页面就全没了；
- AI 的回复是写死的一句"网页端对话服务待接入，敬请期待"，不是真 AI 在答；
- 现在连头像都没有，用户消息就是一个灰方块，AI 消息就是一行裸字，时间戳写死"刚刚"；
- 左边那条 56px 窄栏是全站导航（首页/画图/视频/画布…），**不是**聊天记录列表；
- 空状态只有一句问候语，下面光秃秃没有推荐问题；
- 复制按钮一直挂在每条 AI 消息下面，平时挡眼睛；
- 没有打字机、没有渐入动画、没有日期分割线、没有历史会话。

**这次优化只做前端体验层，不接后端。** 凡是需要后端才能真做的事（历史会话存账号、未读消息推送、文件真上传给 AI），这次只做前端壳子或者直接不做，等后端接入那波再补。

### 用户怎么用

1. 打开 `/chat`，中间是空状态：上面一句问候，下面一排推荐问题卡片，点哪张就把哪句填进输入框（或直接发出去）。

2. 发消息：回车发送，Shift+回车换行。发送按钮空的时候是灰的，一打字就亮起来，按下去有个小回弹。

3. 看对话：自己发的消息在右边，AI 回的在左边，两边都带圆形头像。消息刚出来的时候淡入一下，AI 回复像打字机一样一个字一个字冒。

4. 想看以前聊过什么：聊天页左边多一块会话列表，点"新建对话"开新的，点历史条目切过去。这块列表可以收起来，专注聊天时不挡视线。

5. 嫌旁边栏挡着：点一下专注模式，顶栏和全站导航都藏起来，只留对话和输入框，再点一下（或按 Esc）退出来。

6. 对某条消息有想法：鼠标移上去，浮出一排小按钮（复制、重新生成、删除）；双击消息直接复制全文；长按（或右键）弹菜单。

7. 长回答不想全看：超过七八行的长消息自动折叠成"展开全文"，点了才展开。

8. 想丢文件进去：直接把文件拖到输入框上，框会高亮，松手后文件名贴在输入框上面（真上传给 AI 要等后端，现在只做预览）。

### 业务规则

#### 一、消息外观

1. **<span style="font-size:18px;color:#fff">用户消息右边一个圆头像（用登录后的默认头像），AI 消息左边一个圆头像（机器人图标），跟主流聊天 App 一样，一眼分清谁在说话。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">头像 32px 圆形，用户头像取 useAuthStore.user.avatar，未登录用默认头像；AI 用 Bot lucide 图标，背景 --color-accent-soft</span>

2. **<span style="font-size:18px;color:#fff">自己发的气泡右下角带个小三角指向头像，AI 的气泡左下角带个小三角，像微信那样有个"尾巴"，不是光秃秃的方块。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">用 CSS ::after 三角形，宽 8px，颜色与气泡底色一致；用户气泡右下角对齐头像侧，AI 气泡左下角对齐头像侧</span>

3. **<span style="font-size:18px;color:#fff">消息气泡轻轻浮起来，带一点阴影，不要贴在背景上糊成一片。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">box-shadow: 0 1px 2px rgba(0,0,0,0.06), 0 2px 8px rgba(0,0,0,0.04)；暗色下阴影透明度减半</span>

4. **<span style="font-size:18px;color:#fff">每条消息下面或鼠标悬停时显示真实发送时间（比如 14:32），不再写死"刚刚"。跨天的消息中间插一条日期分割线（今天 / 昨天 / 9月20日）。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">ChatMessage 接口新增 createdAt: number；时间戳默认隐藏，hover 消息行时在气泡下方淡入显示；相邻消息日期不同则渲染居中分割线，文案用相对日期（今天/昨天/M月D日）</span>

5. **<span style="font-size:18px;color:#fff">气泡圆角大小可以在设置里调，三档：小圆角（8px）、中圆角（12px，默认）、大圆角（16px）。调完全站聊天气泡立刻生效。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">useConfigStore 新增 chatBubbleRadius: 8|12|16，气泡 className 用 style={{ borderRadius }} 动态绑定；设置项放在 /settings 页"聊天"分组</span>

#### 二、空状态与输入区

6. **<span style="font-size:18px;color:#fff">没消息的时候，中间问候语下面摆 4–6 张推荐问题卡片，每张是一句完整的话（比如"帮我写一封请假邮件"），点一下就把这句话填进输入框，再点一下发送按钮才发，避免误触。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">推荐问题写在 i18n chat.suggestions 数组里（中/英/日/韩/西五语），点卡片 setInput(text) 并 focus 输入框；卡片为浅灰底圆角卡片，hover 轻微上浮</span>

7. **<span style="font-size:18px;color:#fff">输入框那一行除了现在的"+、语音、发送"，左边再加几个常用工具按钮：上传文件、清空对话。按钮默认是浅灰色，点了有 toast 反馈。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">"+"按钮保留为附件入口；新增 Paperclip（文件）按钮触发隐藏 input[type=file]；新增 Trash2（清空）按钮，清空前弹 ancd Modal.confirm 确认；所有写操作用 App.useApp() 的 message 反馈</span>

8. **<span style="font-size:18px;color:#fff">发送按钮空输入时是灰的不可点，一有文字就亮成实心，按下去有个缩放回弹动画，发送中变成转圈。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">用 motion.button，whileTap={{ scale: 0.9 }}；sending=true 时 Send 图标替换为 antd LoadingOutlined 或 spinner</span>

#### 三、左侧会话侧栏

9. **<span style="font-size:18px;color:#fff">聊天页里面再嵌一层左边栏，顶部一个"+ 新建对话"按钮，下面列历史会话条目（每条显示标题和相对时间），当前会话高亮。这层栏可以点按钮收起来，收起来后聊天内容变宽。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">在 ChatPage 内部加 ChatHistorySidebar 组件，宽 240px，状态存 localStorage('chat-sessions')；折叠按钮用 PanelLeftClose/Open，折叠时宽度 0 并加 transition-all；注意这层侧栏在 AppLayout 那条 56px 全站导航的右边，不是替换它</span>

10. **<span style="font-size:18px;color:#fff">历史会话这次只存在浏览器里，刷新还在，换电脑/换浏览器看不到。等以后接了账号后端，再把会话搬上云端。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">useChatSessions hook 读写 localStorage，schema: { id, title, createdAt, messages: ChatMessage[] }；标题取首条用户消息前 20 字；不调 /api 接口</span>

#### 四、动画与状态

11. **<span style="font-size:18px;color:#fff">每条消息刚出现时从下面轻轻浮上来、淡入，不是"啪"一下砸出来。历史消息不重复播动画，只有新来的才播。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">motion.div initial={{ opacity: 0, y: 8 }} animate={{ opacity: 1, y: 0 }} transition={{ duration: 0.2 }}；历史消息（非 streamId）用 layout="position" 不播 enter 动画</span>

12. **<span style="font-size:18px;color:#fff">AI 回复像打字机一样一个字一个字往外冒，不是一整段突然出现。这版即使后端没接，mock 回复也要走打字机效果。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">setTimeout 改成逐字追加：每 20–30ms 追加 1–2 个字符，光标用 blinking block；将来接 SSE 时直接把 onmessage 事件塞进同一个追加函数</span>

13. **<span style="font-size:18px;color:#fff">AI 正在想的时候，头像旁边三个小圆点轮流跳，比现在一个孤零零的脉冲点像回事。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">三个 6px 圆点，用 motion.span 依次 animate opacity/translateY，stagger 0.15s，infinity loop</span>

14. **<span style="font-size:18px;color:#fff">鼠标不放在消息上的时候，操作按钮藏起来；鼠标移到某条消息上，它下面浮出一排小图标（复制、重新生成、删除），移开又消失。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">消息组 group hover:opacity-100 opacity-0 transition；AI 消息显示复制/重新生成/朗读（朗读先占位），用户消息显示复制/删除；删除弹 Modal.confirm</span>

#### 五、交互细节

15. **<span style="font-size:18px;color:#fff">一条消息超过七八行就自动折起来，下面一个"展开全文"按钮，点了才全显示，再点收起。短消息不折叠。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">判断内容行数 > 8（按 \n 数或 line-clamp），默认 line-clamp-8，展开后 clamp-none；按钮文案"展开全文/收起"</span>

16. **<span style="font-size:18px;color:#fff">双击任意一条消息直接复制全文，弹 toast 告诉你复制好了，不用先找复制按钮。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">onDoubleClick 触发 navigator.clipboard.writeText，App.useApp().message.success(t('chat.copied'))</span>

17. **<span style="font-size:18px;color:#fff">在消息上长按（手机）或右键（电脑），弹一个小菜单：复制、重新生成、删除。删除要二次确认。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">onContextMenu 阻止默认菜单，弹自定义浮层；移动端用 onTouchStart + 500ms timer；删除走 Modal.confirm</span>

18. **<span style="font-size:18px;color:#fff">把电脑里的文件直接拖到输入框上，输入框边框高亮一下，松手后文件名贴在输入框上方，像微信发文件那样。现在还不能真发给 AI，发了会提示"文件发送能力即将上线"。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">onDragOver/onDragLeave/onDrop 处理；拖入时 outline 高亮 --color-accent；选中文件存 state 显示 chips，发送时 message.info(t('chat.uploadSoon'))；不调上传接口</span>

19. **<span style="font-size:18px;color:#fff">任何弹窗（登录、菜单、确认框）按 Esc 就关。双击聊天空白处，光标立刻跳进输入框。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">全局 keydown Escape 关闭当前浮层；消息容器 onDoubleClick={() => textareaRef.current?.focus()}</span>

#### 六、个性化与专注

20. **<span style="font-size:18px;color:#fff">点一下"专注模式"，顶栏和左边全站导航都藏起来，聊天区占满整个屏幕，专心写东西。再点一下或按 Esc 退出来。</span>**<br>

21. **<span style="font-size:18px;color:#fff">强调色可以在设置里换：紫（默认）、蓝、绿、橙、粉五个预设，点一下全站按钮、链接、高亮立刻变色。不做自由取色器。</span>**<br>

3. **强调色**：5 个预设色够不够？不要自由取色器对吧？
4. **专注模式**：是只隐藏聊天页自己那层会话栏，还是连顶部导航+全站 56px 侧栏一起藏？后者要改 AppLayout，影响面大一点。

### 出问题怎么办

- 打字机一卡一卡 → 调逐字间隔（20ms 起步），避免每字都触发 React 重渲染整条消息
- 拖拽文件拖进去没反应 → 确认 onDrop 阻止了默认行为（浏览器默认会打开文件）
- 双击选中文字时不小心触发复制 → 双击复制要判断当前没有文本选中（window.getSelection().toString() === ''）
- 折叠按钮在短消息上闪一下 → 先量内容高度再决定渲染不渲染展开按钮，不要渲染了再判断
- 会话侧栏收起/展开时布局抖动 → 给 aside 固定宽度 transition，不要用 width:auto
- 强调色换了但某些按钮没变 → 检查有没有硬编码 #5051f8 的地方，全部换成 var(--color-accent)
