# 聊天界面增强功能

### 这是什么

给聊天面板加一批日常用得到的小功能：消息静音、给消息写备注、高亮重点消息、发失败了能重发、断网了有提示、隔久了显示时间、一键清空记忆、表格导出 Excel、右键菜单、AI 回复能朗读、对话自动整理目录等等。都是聊天时天天碰到的小事，凑在一起让聊天更好用。

### 现在长什么样

目前聊天面板只有基础功能：发消息、看回复、复制回复、重新生成、看历史对话列表。下面 21 个功能里，大部分还没做，少数有半成品：

- 复制按钮：AI 回复右上角已有复制按钮
- 重新生成：AI 回复右上角已有刷新按钮
- 工具失败红标：工具调用失败会显示红色叉号，但你自己发的消息发失败了不能重发
- 断连状态：历史对话列表能看到"已连接/未连接"，但聊天区顶部没有断网提示条，也不会自动重连
- 表格复制：AI 回复里的表格能复制文字，但不能下载成 Excel
- 音频设置：现有音频设置面板是用来"生成音频文件"的，不是用来"朗读聊天回复"的，两回事

## 一、其他实用

1. **<span style="font-size:18px;color:#fff">某个对话不想被新消息打扰，可以单独把它静音。静音后这个对话有新回复时不弹通知、不响提示音，但对话列表里它会安静地待在那里，你自己想看再点开。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">thread 数据加 muted 标记，存 localStorage 或服务端 thread 字段；通知触发时检查 muted 跳过 Notification API 和提示音；历史列表项显示静音图标</span>

2. **<span style="font-size:18px;color:#fff">任意一条消息下面可以加一段只有自己能看到的小备注。比如 AI 说了一段话，你觉得以后要查，就给它写个备注"这个参数下周要试"，备注只有你自己看得到。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">消息数据加 note 字段，前端 localStorage 按 messageId 存；消息下方显示备注图标，点击展开编辑；备注不发给后端，不影响上下文</span>

3. **<span style="font-size:18px;color:#fff">觉得某条消息重要，可以给它标个颜色高亮。高亮的消息在聊天记录里一眼就能找到，跟荧光笔划重点一样。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">消息加 highlightColor 字段（无/黄/绿/蓝），消息容器加背景色类；localStorage 持久化；右键菜单选颜色</span>

---

## 二、状态提示

4. **<span style="font-size:18px;color:#fff">你发的消息如果没发出去（网络断了、服务器没响应），这条消息旁边会出现红色感叹号，点一下就能重新发，不用把话重新打一遍。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">AgentChatMessageItem 加 status: 'sending' | 'sent' | 'failed'；failed 时用户消息右侧显示重发按钮，点击把原文塞回 composer 重新发送</span>

5. **<span style="font-size:18px;color:#fff">网断了的时候，聊天顶部会出现一条黄色提示"网络已断开，正在重连……"，不用你手动刷新。网恢复了提示自动消失。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">监听 navigator.onLine 和 WebSocket close 事件；聊天区顶部固定 Banner；重连用指数退避，onLine 事件触发立即重试；重连成功后 toast 提示"已恢复连接"</span>

6. **<span style="font-size:18px;color:#fff">两条消息之间如果隔了很久（比如半小时），中间会出现一条灰色时间分隔线，写着"下午 3:20"，让你知道哪段话是之前聊的、哪段是现在接着说的。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">遍历 messages，相邻两条时间戳间隔超过 30 分钟时插入时间分隔行组件；用 message.timestamp 计算，格式化为本地时间</span>

---

## 三、上下文控制

7. **<span style="font-size:18px;color:#fff">输入框旁边有个"清空"按钮，点一下弹确认框，确认后当前对话的所有消息记录全部清掉，AI 就不记得之前聊过什么了，相当于开了个新对话但还在原来的窗口里。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">清空 useAgentStore.messages，调后端清空 thread 上下文；操作前 antd Modal.confirm 确认；清空后 toast 提示"已清空上下文"</span>

8. **<span style="font-size:18px;color:#fff">输入框上面显示"已经聊了 12 轮"，让你知道现在 AI 还记得多少。聊得太多、上下文快满的时候会提醒你"建议开新对话"。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">统计 messages 中 user/assistant 交替次数为轮数；调 /api/billing/me 或 thread context length 返回剩余 token，接近上限时黄色提示条</span>

9. **<span style="font-size:18px;color:#fff">看到某条消息里有一段话想接着聊，可以右键选"引用到输入框"，那段话就自动塞进输入框里，你在后面接着写就行。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">右键菜单加"引用"选项，取 message 全文或鼠标选中的文本，追加到 composer；滚动回输入框并聚焦</span>

---

## 四、内容操作

10. **<span style="font-size:18px;color:#fff">AI 回复里如果有表格，表格右上角会有个"导出"按钮，点一下就能下载成 Excel 文件，直接用 Excel 或 WPS 打开。</span>**<br>
    <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">Streamdown table controls.download 设为 true，或自定义表格工具栏；用 SheetJS(xlsx) 把 markdown table 转 .xlsx 下载；文件名用对话标题+时间</span>

11. **<span style="font-size:18px;color:#fff">AI 回复里如果画了图表（柱状图、折线图这些），图表上面会有下载按钮，点一下存成 PNG 图片，方便贴到别的文档里。</span>**<br>
    <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">检测 message 中的图表渲染节点，工具栏加下载 PNG 按钮；用 html-to-image 或图表库自带 getDataURL 导出</span>

12. **<span style="font-size:18px;color:#fff">AI 回复完了觉得哪里写错了，可以直接点编辑改它，改完以后这条回复就变成你改过的版本，后续 AI 也会基于你改过的版本继续聊。</span>**<br>
    <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">assistant 消息加编辑模式，点击编辑切换为 textarea；保存后调后端更新消息内容，标记 editedAt；编辑过的消息显示"已编辑"小字</span>

---

## 五、交互细节

13. **<span style="font-size:18px;color:#fff">在任何一条消息上点鼠标右键，弹出一个菜单：复制、引用到输入框、加备注、高亮、删除这条消息。不用找按钮，右键就够了。</span>**<br>
    <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">AgentChatMessage 容器 onContextMenu 触发自定义右键菜单；菜单项根据消息角色（用户/AI/系统）动态显示；删除消息需确认弹窗</span>

14. **<span style="font-size:18px;color:#fff">用鼠标选中消息里的一段文字，旁边自动弹出一个小浮条，点"复制"就复制了，不用按 Ctrl+C。</span>**<br>
    <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">监听 mouseup，window.getSelection() 非空且在消息区域内时，在选区上方渲染浮动复制按钮；点击写 clipboard 并 toast 提示</span>

15. **<span style="font-size:18px;color:#fff">你切到别的窗口干活的时候，AI 回复完了会在电脑右下角弹一个桌面通知，"叮"一声提醒你。点通知直接跳回聊天窗口。可以在设置里关掉。</span>**<br>
    <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">Document.hidden 时新 assistant 消息触发 new Notification(title, {body, icon})；播放短促提示音；用户可在设置里开关通知和提示音</span>

---

## 六、语音输出

16. **<span style="font-size:18px;color:#fff">每条 AI 回复上面有个小喇叭，点一下就用语音读出来。可以在设置里选声音：男声、女声、温柔、沉稳，跟选输入法皮肤一样。</span>**<br>
    <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">用 Web Speech API speechSynthesis，voice 列表从 speechSynthesis.getVoices() 选；设置存 localStorage；注意现有 audio-settings-panel 是生成音频文件用的，跟朗读回复不是一回事</span>

17. **<span style="font-size:18px;color:#fff">觉得 AI 读得太快或太慢，可以在设置里调语速，从 0.5 倍到 2 倍，滑条拖动即时生效。</span>**<br>
    <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">speechSynthesis.rate 范围 0.5–2.0，设置持久化；跟 TTS 声音选择放同一个设置面板</span>

18. **<span style="font-size:18px;color:#fff">可以开一个"自动朗读"开关，以后每条 AI 回复一出来就自动念给你听，不用每次点喇叭。适合闭眼听的时候。</span>**<br>
    <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">自动朗读开关存 localStorage；assistant 消息流式结束后检测开关，自动触发朗读；切换对话或手动点停止时 cancel；静音对话不自动朗读</span>

---

## 七、对话管理

19. **<span style="font-size:18px;color:#fff">一个对话聊了很长以后，左边自动生成一个目录，把聊过的主题分节列出来，点一下就跳到那段。不用自己翻半天找之前聊了什么。</span>**<br>
    <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">按时间间隔或用户消息切分话题组，提取每组首条用户消息做标题；渲染为侧栏目录，点击 scrollIntoView 定位到对应消息</span>

20. **<span style="font-size:18px;color:#fff">一个对话如果 7 天没打开，自动挪到"已归档"文件夹里，不在主列表里碍事。想找的时候去归档里翻，随时能恢复出来。</span>**<br>
    <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">thread 数据加 archivedAt 字段；前端按 updatedAt 超过 7 天自动标记归档；历史列表加"归档"筛选，归档项默认折叠；可手动恢复或永久删除</span>

### 花多少钱

大部分是纯前端功能，0 元：

- 表格导出 Excel：SheetJS 库免费开源
- 图表下载图片：html-to-image 免费
- 桌面通知和提示音：浏览器原生 API，免费
- TTS 朗读：Web Speech API 免费，用系统自带声音
- 备注、高亮、右键菜单、时间分隔、归档：纯前端，免费

唯一可能花钱的：如果 TTS 想用比系统自带更好听的声音，需要接第三方 TTS 服务，按调用量计费。先用免费的系统声音，以后有需要再接。
