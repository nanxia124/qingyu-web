# 开发环境连接方案

## 当前状态

数据库和测试 API 仍在整理中，本地页面暂时继续使用现有配置。本阶段不修改生产数据库，也不修改数据库迁移，避免和数据库维护工作冲突。

## 目标环境

| 环境 | 地址 | 数据 | 用途 |
| --- | --- | --- | --- |
| 本地开发 | `http://localhost:5173` | 测试数据 | AI 修改和页面调试 |
| 开发预览 | `https://dev.litzone.art` | 测试数据库 | 手机和其他设备查看效果 |
| 正式环境 | `https://litzone.art` | 正式数据库 | 真实用户使用 |

## 切换原则

1. 浏览器只连接 API，不直接连接 PostgreSQL。
2. `localhost:5173` 和 `dev.litzone.art` 只能连接测试 API。
3. `litzone.art` 才能连接正式 API。
4. 测试数据库准备好后，只修改开发环境的 API 地址，不修改业务页面代码。
5. 上线前先在 `dev.litzone.art` 验证，再部署正式环境。
