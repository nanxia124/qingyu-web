# 侧边栏语言菜单怎么用

1. **<span style="font-size:18px;color:#fff">左下角那个地球图标，你点一下它才弹出语言列表；鼠标移上去不会自己弹出来，你不点它就一直安安静静待着。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">AppLayout.tsx 语言切换按钮用 onClick toggle，不用 onMouseEnter/onMouseLeave 悬浮触发</span>

1. **<span style="font-size:18px;color:#fff">语言列表弹出来之后，你随便点页面上别的地方——点空白、点别的按钮、点顶栏——这个列表自己就收回去了，不用再点一次地球。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">useRef + document mousedown 监听，点击在菜单容器外就 setLangMenuOpen(false)</span>

1. **<span style="font-size:18px;color:#fff">列表里现在只列六个语言：英语、日语、韩语、西班牙语、简体中文、繁體中文。其他十几门语言的翻译文件都还在代码里，只是先不摆出来；以后想加回来，在 VISIBLE_LOCALES 数组里补上语言代号就行。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">VISIBLE_LOCALES = ['en-US','ja-JP','ko-KR','es-ES','zh-CN','zh-TW']；LANG_LABELS/LANG_FLAGS/locales 文件全部保留，菜单只 map VISIBLE_LOCALES</span>

1. **<span style="font-size:18px;color:#fff">这个弹窗不要画边框，只要阴影就行，跟整站暗色风格保持一致。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">弹窗 div 去掉 border border-border，只保留 rounded-xl bg-card shadow-xl</span>

1. **<span style="font-size:18px;color:#fff">第一次打开网站的人，系统会按他所在的地区自动给合适的语言（比如中国给简体中文），不用他自己找；同时顶部弹一个提示条，上面有"撤销"和"×"两个按钮——这个提示条不会自己消失，只有他点了按钮才消失。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">canvas/i18n/index.ts autoDetectLanguageByIP：未手动选择（locale-manual≠true）时按 IP 自动 changeLanguage 并保存 locale，通知 AppLayout 弹条；提示条无自动消失定时器，撤销=changeAppLocale(previousLocale)，×=setSuggested(null)</span>
