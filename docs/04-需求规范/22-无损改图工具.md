# 无损改图工具

### 这是什么

用 AI 改完图以后，哪怕你只改了脸上一个痣，整张图都会被重新压一遍，画质就糊了。这个工具的作用是：把 AI 改过的那一小块地方精准地抠出来，贴回原图上，其他地方完全用原图的像素，这样除了改动的部分，画质跟原图一模一样。

### 用户怎么用

1. 打开工具页，先传第一张图——**原图**（就是你最开始那张、画质最好的那张）

2. 再传第二张图——**AI 修改后的图**（用各种 AI 工具改完的那张）

3. 工具自动做三件事：先把两张图对齐（AI 输出的图经常会歪一点、缩一点），再自动校色（AI 改完整体会偏色），然后自动圈出哪些地方变了

4. 自动圈完以后，你拿画笔涂一涂：觉得哪里不该改的，用「还原」画笔涂回去；觉得哪里改了但没圈到的，用「修改」画笔涂上去

5. 觉得满意了，点导出，存成 PNG 或者三层 PSD（拿去 PS 里还能继续改）

### 现在长什么样

还没开始做。下一步：先把页面架子搭起来，两个上传框放好，再一步步加自动对齐、自动校色、自动找改动区域这些功能。

### 业务规则

1. **<span style="font-size:18px;color:#fff">两张图都传完以后，自动开始对齐和校色，不用用户点按钮。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">setOriginal 和 setAi 都完成后自动触发 autoAlign() → computeCorrection() → analyzeChanges() → composite() → render()，全程异步不卡界面</span>

2. **<span style="font-size:18px;color:#fff">AI 输出的图大小、位置可能跟原图不一样，先自动对齐再比，不然差一点点就全算成改动了。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">多尺度由粗到细对齐：先缩到 256/512/1024 宽度做全局平移对齐，再分块（约 1/4 屏大小）做局部精对齐，最后用加权最小二乘拟合 sx/sy/tx/ty 四个参数，对齐残差 > 2.5px 时弹警告提示用户用大画笔</span>

3. **<span style="font-size:18px;color:#fff">AI 改完的图整体会偏色（比如偏蓝、偏红），自动反过来校正回去，不然贴回原图的时候颜色接不上。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">采样未变化区域的像素（mask 不透明度 < 8 且两图 RGB 差 < 96），按 R/G/B 三通道分别算均值和方差，用线性 gain + offset 校正，gain 限制在 0.85~1.18 之间防止过校正，校正强度 k 默认 1 可手动调</span>

4. **<span style="font-size:18px;color:#fff">自动找出两张图不一样的地方，圈成一块一块的，用户可以点一下就采纳或者不采纳。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">两种互补指标：①平均颜色差（检测颜色变化）②绝对像素差（检测纹理变化），用中位数 + MAD 鲁棒估计阈值（med + 8*MAD，最小阈值 6），二值化后做形态学开运算去毛刺，再连通域分析分成独立 blob，按面积排序，明显的自动采纳，不明显的框出来让用户点</span>

5. **<span style="font-size:18px;color:#fff">如果检测到整张图 30% 以上都变了，自动切换思路：反过来找"没怎么变的前景"（比如人物）保留，其他地方都用 AI 图——适合背景整体替换的场景。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">changedShare >= 0.3 时触发 bgMode，反向找 dmA < Tlow 的区域作为 keep 前景，面积 > 1% 画布的 keep 块保留原图，其余全部用 AI 图</span>

6. **<span style="font-size:18px;color:#fff">画笔可以调大小和硬度，两种模式：「修改」是把这部分换成 AI 图，「还原」是这部分用回原图。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">brush.size 默认 160px，hardness 默认 0.5（边缘羽化），mode='erase' 表示擦除蒙版=用AI图，mode='restore' 表示涂回蒙版=用原图，画笔形状是高斯衰减的圆形</span>

7. **<span style="font-size:18px;color:#fff">支持撤销和重做，手滑涂错了能退回去。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">pushUndo 时保存 mask 画布的 ImageData，undo 栈和 redo 栈分别管理，每次画笔开始画之前 push 一次，不是每个像素 push</span>

8. **<span style="font-size:18px;color:#fff">可以按住对比看原图和改完的区别，也可以开蒙版模式看哪些地方被换了。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">peek 模式按住空格临时显示原图，showMask 模式用半透明红色叠加显示蒙版区域，compare 模式左右分屏对比</span>

9. **<span style="font-size:18px;color:#fff">导出可以存成 PNG，也可以存成三层 PSD——原图一层、AI 图一层、蒙版一层，拿去 PS 里还能继续调。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">PNG 用 canvas.toBlob 导出；PSD 自写最小 PSD 解析器，三层结构：底图层=原图，中间层=AI校正后图，顶层=蒙版（图层蒙版），支持 8bit RGB</span>

10. **<span style="font-size:18px;color:#fff">所有处理都在浏览器本地跑，一张图都不会传到服务器，隐私安全。</span>**<br>
    <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">纯前端 Canvas API 实现，不调用任何后端接口，所有像素操作都在内存里完成，页面上明确提示"图片只在你的浏览器里处理，不会上传"</span>

11. **<span style="font-size:18px;color:#fff">支持点击上传、拖进去、直接粘贴三种方式传图，怎么方便怎么来。</span>**<br>

12. **<span style="font-size:18px;color:#fff">如果两张图宽高比差超过 1%，自动拉伸对齐，并且提醒用户。</span>**<br>
    <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">ar = W/H，ar0 = origW/origH，|ar - ar0|/ar0 > 0.01 时 status 条显示警告"两图比例不同，已拉伸"</span>

    <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">背景 #0a0a0a，卡片 #1a1a1a，强调色蓝紫色，所有组件不写 border，用背景色差异区分层级</span>

### 出问题怎么办

* 两图对不齐 → 看对齐残差提示，残差大的话用大一点的画笔涂改动区域边缘
* 颜色接不上 → 检查校色信息，采样像素太少的话手动调 R/G/B 三个通道的手动偏移
* 自动圈的改动区域不准 → 用画笔手动补或者擦，不满意可以撤销重来
* 导出的 PSD 在 PS 里打不开 → 确认是 RGB 模式 8bit，不要带 CMYK 或 16bit
