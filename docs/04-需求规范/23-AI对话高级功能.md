# AI 对话高级功能

### 这是什么

现在聊天页是个空壳：你打字发出去，它假装等 400 毫秒，回你一句"服务待开通"，刷新页面就全没了。这份需求要做两件事：第一，把聊天页从空壳改成真的能跟 AI 对话（真调模型、边生成边出字、排版好看）；第二，在真对话的基础上加你列的这些高级能力——聊到一半能分叉重答、能撤回改字、草稿自动存、中途换模型不丢上下文、单条失败单独重发、数学公式和表格能正常显示、图表直接画出来、思考过程能折叠看、能设 AI 记几轮、每条消息有准确时间、手机上手势好用。

### 用户怎么用

1. 打开聊天页，选好右上角的模型，直接打字问问题，按回车发送

2. AI 一边想一边一个字一个字往外蹦，不用等它全写完才看到；想停就点"停止"

3. AI 回复里如果有数学公式、表格、流程图，自动排成好看的样子，不是一堆符号

4. 如果这条 AI 答得不满意，从它那个岔路口重新生成一个版本，左右箭头来回对比两个版本

5. 自己发出去的话说错了，撤回来改两个字再发；某条消息发失败了，单独点那条重发，不用整条对话重来

6. 聊到一半想换个模型答，直接在右上角切，前面聊的内容新模型都接着

7. 输入框里打了一半没发，关了页面再打开，字还在

8. 鼠标放在任何一条消息上，能看到这条是几点几分几秒发的

9. 手机上打开，手指滑动、输入、看长文都顺手

### 现在长什么样

还没开始做。现在 `src/pages/ChatPage.tsx` 是个纯前端壳：发消息后 `setTimeout` 400ms 假延迟，固定回复"服务待开通"，消息只存在内存里，刷新即丢；没有接后端、没有流式输出、没有 Markdown 渲染、没有时间戳、没有失败状态。后端已经有一个无状态代理 `/api/proxy/openai/chat/completions` 可以真调上游大模型并扣积分，但不存对话历史。

要做的事分两期：**一期**先把真对话跑通（接流式、Markdown/代码块、消息状态、草稿、时间戳、失败重试、换模型）；**二期**再做对话分支分叉、消息撤回编辑、图表生成、思维链折叠、上下文轮数设置、移动端手势打磨。

   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">POST /api/proxy/openai/chat/completions，stream:true，fetch ReadableStream 逐块解析 SSE data: 行，delta.content 追加到当前 assistant 消息；AbortController 中断流，已接收内容保留不回滚</span>

   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">react-markdown 渲染消息内容，组件覆盖：a 新窗口打开 target=_blank rel=noreferrer，ul/ol 正常缩进，blockquote 左边框灰条，strong/b 加粗</span>

3. **<span style="font-size:18px;color:#fff">AI 回复里的代码块要好看：有语言标签、有语法高亮、右上角有复制按钮，长代码能横向滚动。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">react-markdown code 组件走 react-syntax-highlighter（prism 暗色主题），pre 块深色背景圆角，右上角复制按钮调 navigator.clipboard，hover 显示，复制成功变"已复制"</span>

4. **<span style="font-size:18px;color:#fff">每条消息有三种状态：发送中（转圈/脉冲点）、成功（正常显示）、失败（红字提示+重发按钮）。失败了只重发那一条，不影响别的消息。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">ChatMessage.status: 'sending' | 'success' | 'error'；error 时消息下方显示"发送失败"+重试按钮，点击重发时把该条之前的完整 messages 重新 POST，不改其他消息；AbortError/网络错误/4xx/5xx 统一归类</span>

5. **<span style="font-size:18px;color:#fff">单条消息失败单独重试：点失败消息上的"重发"按钮，只把这一条用户消息和它之前的上下文重新发给 AI，原来那条失败的 AI 回复替换成新的，对话里其他消息一动不动。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">retryMessage(msgId)：截取 messages 数组到该 user 消息为止，重新发起 stream，把对应位置的 assistant 占位消息替换为新流；失败不重复扣积分（上游 402/5xx 时由后端退款逻辑兜底）</span>

6. **<span style="font-size:18px;color:#fff">输入框里打了一半没发，切走页面、刷新、关掉浏览器再打开，字还在；发出去以后草稿自动清空。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">input onChange 防抖 300ms 写 localStorage 键 `chat:draft:{conversationId}`，send() 成功提交后 removeItem；多会话草稿按 conversationId 隔离；首次打开空会话时读 `chat:draft:new`</span>

7. **<span style="font-size:18px;color:#fff">每条消息都有准确的发送时间：刚发的时候显示"刚刚"，过几分钟显示"x 分钟前"，鼠标放上去（手机上长按）显示完整的"2026-09-26 14:32:08"。用户消息和 AI 消息都要有。</span>**<br>

8. **<span style="font-size:18px;color:#fff">聊到一半在右上角换了个模型，接下来发的消息用新模型答，但前面聊过的内容新模型都记得，不用从头再讲一遍。</span>**<br>

### 出问题怎么办

* AI 半天不出字 → 看是不是网络断了，点"停止"再重发；长时间没响应检查积分余额
* 公式显示成一堆 $ 符号 → 该模型没按 LaTeX 格式输出，手动让它"用标准 LaTeX 重写公式"
* 流程图渲染失败 → 点图右上角"源码"看 mermaid 代码，复制出来去 mermaid.live 排查
* 换模型后 AI 听不懂前文 → 新模型上下文窗口小，把上下文轮数调小或者开新对话
* 草稿丢了 → 检查是不是开了隐私模式，隐私模式下 localStorage 不持久
* 手机上输入框被键盘挡住 → 页面会自动顶开，如果没顶开刷新页面
