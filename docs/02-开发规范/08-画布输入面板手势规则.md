# 画布输入面板手势规则

下面这些是节点输入面板（图片/视频/音频/文本节点弹出的那个输入框）已经验证过的手势规矩，以后改这块要照着来。

1. **<span style="font-size:18px;color:#fff">鼠标停在输入面板上滚滚轮：输入框里的提示词还能上下翻就先翻提示词，翻到顶或翻到底之后，再滚滚轮才是缩放画布。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">节点输入面板根节点带 data-canvas-panel-zoom 标记；infinite-canvas.tsx 的 handleWheel / preventWheelScroll 先调 canScrollInDirection() 判断目标元素在滚轮方向上是否还能滚动，能滚就放行原生滚动，到边界才接管缩放并 preventDefault。其他浮层（Modal、Popover、下拉）维持原行为，滚轮不缩放画布。</span>


2. **<span style="font-size:18px;color:#fff">按住中键拖动、按住空格再按左键拖动、按住 Ctrl 再按左键拖动：在输入面板上都能直接平移画布；但左键点在输入框里时，还是正常选文字、定位光标，不会触发平移。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">面板根 div 的 onPointerDown/onMouseDown 用 shouldPassthrough() 判断放行：中键（button===1）一律放行；左键（button===0）只要目标不在 input/textarea/select/button/[contenteditable='true'] 内就放行。画布 handlePointerDown 里 panGesture = button===1 || (button===0 && (getModifierState('Space') || event.ctrlKey))，panel-zoom 区域内绕过 isBackgroundClick 限制进入平移。空格/Ctrl 状态统一用 event.nativeEvent.getModifierState() 读，不要在面板和画布两边各挂一套 keydown 监听。</span>


3. **<span style="font-size:18px;color:#fff">左键直接按在面板空白处长按拖动，能移动这个节点卡片；按在输入框里是打字，按在按钮上就是点按钮。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">shouldPassthrough() 放行普通左键后，事件冒泡到面板浮层包裹 div（canvas-node.tsx 里 top-full z-[70] 那个）的 onMouseDown，它必须调用 onMouseDown(event, data.id) 进入节点拖动逻辑。漏挂这一层的话，面板上的鼠标动作传不到节点，卡片拖不动。</span>


4. **<span style="font-size:18px;color:#fff">在空输入框里打中文时，灰色提示文案立刻消失，不会和输入法候选词叠在一起；打完字正常显示输入的内容。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">canvas-prompt-chip-input.tsx 增加 composing state：onCompositionStart 时 setComposing(true) 并隐藏浮层 placeholder（showPlaceholder = !value.trim() && !composing），onCompositionEnd 时复位并 syncFromEditor()。原因是输入法组词期间不向外 emit value，原先只看 value.trim() 会让浮层提示一直盖在正在输入的拼音上。</span>


5. **<span style="font-size:18px;color:#fff">面板根节点同时挂两个标记：data-canvas-no-zoom 和 data-canvas-panel-zoom。普通浮层只挂前者，节点输入面板两个都挂。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">data-canvas-no-zoom = 这是浮层，画布默认不接管手势；data-canvas-panel-zoom = 这个浮层是节点输入面板，滚轮/平移要智能放行。普通弹层、弹窗、下拉只挂 data-canvas-no-zoom（完全拦截）。新做节点输入面板必须两个都挂，别再自己 onWheel stopPropagation。</span>
