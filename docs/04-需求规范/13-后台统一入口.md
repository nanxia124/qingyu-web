# 后台统一入口规范

### 这是什么
管理员的后台管理页面，从一个隐藏地址进去就能管所有用户、看计费、看系统状态。

### 用户怎么用
- 浏览器输隐藏地址 /admin-secret-8f3k2x7z
- 输管理员账号密码登录
- 左边菜单点哪个看哪个，不用重新登录

### 现在长什么样
- ✅ 所有后台模块在一个后台里，旧地址自动跳转
- ✅ 管理后台顶栏显示轻域小怪兽图标、LitZone 文字 Logo 和“管理运营后台”；本地地址显示“本地开发”，生产地址不显示环境标识；旧品牌名和副标题已移除
- ✅ 浏览器标签页使用轻域小怪兽图标，标题显示 LitZone 品牌文案；标签页图标与页面里的文字 Logo 分开设置
- ✅ 左侧菜单不再显示通用的“后台导航”标题，保留“核心配置”“用户与运营”“系统”分组
- ⚠️ 后台危险操作仍需按模块逐项核对二次确认，不能据单个页面推定全部完成

## 目标

1. **<span style="font-size:18px;color:#fff">后台管理入口放在不显眼的位置，管理员登录后可以在一个页面查看所有运营数据、使用记录和管理功能。管理员只登录一次，左侧菜单切换不同功能，不用每个功能重新登录。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">API 配置、开源项目数据、注册用户、租户、计费、审计和运行监控统一从 /admin-secret-8f3k2x7z 进入；管理员只登录一次，后台模块之间通过侧栏切换</span>


API 配置、开源项目数据、注册用户、租户、计费、审计和运行监控统一从 `/admin-secret-8f3k2x7z` 进入。管理员只登录一次，后台模块之间通过侧栏切换。

## 约定

2. **<span style="font-size:18px;color:#fff">管理员登录凭证和普通用户登录凭证分开保存，互不混淆。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">管理员登录凭证保存为 admin_token，普通用户凭证保存为 token</span>


3. **<span style="font-size:18px;color:#fff">同一个人既是管理员又是普通用户时，优先用管理员身份，不用普通用户身份去访问后台。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">共用 API 请求封装时，管理员 token 优先于普通用户 token</span>


4. **<span style="font-size:18px;color:#fff">原来分散在好几个旧地址的后台模块（管用户的、管计费的、管监控的）现在都统一从隐藏入口进；访问旧地址会自动跳到隐藏入口，不再各自出现登录页。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">/admin 及旧地址 /admin/users、/admin/tenants、/admin/audits、/admin/billing、/admin/monitor 必须跳转到隐藏入口 /admin-secret-8f3k2x7z?section=...，不再各自渲染登录入口</span>


5. **<span style="font-size:18px;color:#fff">以后新加的后台功能，优先加到同一块左侧菜单上；实在要单独做一个页面，也共用管理员已登录的状态，不让管理员再登一次。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">新增后台模块时，优先加入 AdminConsole 的侧栏和 section 映射；需要独立页面时仍复用同一个管理员登录状态</span>


6. **<span style="font-size:18px;color:#fff">管理后台顶栏沿用网站的小怪兽图标和 LitZone 文字 Logo，旁边写“管理运营后台”；在本地打开时清楚标出“本地开发”。左边导航直接显示功能分组，不再额外写“后台导航”。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">`AdminConsole` 复用 `QingyuLogoIcon`、`/litzone-wordmark.svg` 和 `EnvironmentBadge`；localhost/127.0.0.1 显示“本地开发”，开发预览显示“开发预览”，生产域名隐藏环境标识。侧栏保留“核心配置”“用户与运营”“系统”分组，不渲染通用“后台导航”标题。</span>


7. **<span style="font-size:18px;color:#fff">浏览器标签页显示小怪兽图标，页面里的 LitZone 文字 Logo 继续放在页面内容中；标签页标题显示 LitZone 品牌文案。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">`index.html` 的 favicon 指向 `/icons/logo.svg`；页面文字 Logo 使用 `/litzone-wordmark.svg`。浏览器标题及运行时 `document.title` 使用“LitZone · 全球视觉设计师、创作者/团队的智能AI创意助手 ~”，由 `index.html` 和 `src/canvas/i18n/locales/zh-CN.ts` 保持一致。</span>


- 管理员登录凭证保存为 `admin_token`，普通用户凭证保存为 `token`。
- 共用 API 请求封装时，管理员 token 优先于普通用户 token。
- `/admin` 以及旧地址 `/admin/users`、`/admin/tenants`、`/admin/audits`、`/admin/billing`、`/admin/monitor` 必须跳转到隐藏入口 `/admin-secret-8f3k2x7z?section=...`，不再各自渲染登录入口。
- 新增后台模块时，优先加入 `AdminConsole` 的侧栏和 `section` 映射；需要独立页面时仍复用同一个管理员登录状态。

## 前台模型列表

6. **<span style="font-size:18px;color:#fff">生图页一打开，先去服务端拿一份最新的"今天能选哪些模型"清单，再把下拉框摆出来；别用旧清单凑合。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">/image 页面必须调用统一的 ensureServerConfig，把服务端公开渠道同步到 useConfigStore</span>


7. **<span style="font-size:18px;color:#fff">下拉框只能摆从服务端拿回来的那串型号；光改"当前选中哪一个"不会重新刷新整串清单，容易导致下拉框里只孤零零显示默认那一个。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">模型选择器只读取 useConfigStore 的渠道模型；只更新当前选中值不会刷新下拉列表，容易导致页面只显示默认模型</span>


- `/image` 页面必须调用统一的 `ensureServerConfig`，把服务端公开渠道同步到 `useConfigStore`。
- 模型选择器只读取 `useConfigStore` 的渠道模型；只更新当前选中值不会刷新下拉列表，容易导致页面只显示默认模型。
