# 前台布局规范

### 这是什么
规定网站前台长什么样、间距多大、顶部栏和侧栏怎么摆。

### 用户怎么用
- 顶部固定栏：左边 logo、中间搜索、右边"我的"
- 左侧栏点一下收起成图标，再点展开
- 生图页下面有标签切换，模型下拉框在右边

### 现在长什么样
- ✅ 顶部栏统一、侧栏能收放、模型列表从后端拉、主题默认跟随系统深浅色、深色页面底色调成深灰、画布背景跟生图页卡片同色
- ✅ 共用模型选择框已明确设置主题文字色，模型名称和跟随文字颜色的图标随明暗主题切换；类型检查和生产构建通过
- 待验证：浏览器工具连接失败，模型选择框在明暗主题下的实际显示效果尚未完成视觉确认
- ❌ 不同屏幕宽度下错位还没全测

   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">图像页左侧设置卡片与公共侧栏之间只留 8px 外间距；页面外层收窄左侧 padding 时不得改变侧栏宽度或卡片内部间距</span>


11. **<span style="font-size:18px;color:#fff">模型下拉框要等服务端把"今天有哪些模型"送来了再摆出来；没送来就老实显示"暂未获取到模型"，别先塞几个假模型凑数再被真清单换掉。也不许偷偷内置示例模型当可选项。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">全局模型选择器统一等待服务端模型配置完成后再显示；没有可用模型显示"暂未获取到模型"，不得先显示本地默认模型再被远程列表替换；前端不得内置示例模型，模型名只能来自服务端配置</span>


12. **<span style="font-size:18px;color:#fff">模型下拉弹出来的那层浮板，用比卡片稍亮一点的深色，让列表和背景分得清；视频页弹出来的浮板也用同一个颜色。</span>**<br>

13. **<span style="font-size:18px;color:#fff">网站默认跟着你电脑系统的深浅色走；左边栏底部那个月亮/太阳按钮可以手动切浅色或深色，切了之后网站就记住你的选择。画布底部工具栏和画布侧栏里不再放主题切换按钮。刚打开网站那一下也不会闪一下黑底或白底。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">use-theme-store.ts 默认 mode=system，theme 按系统偏好解析为 light/dark；AppLayout 侧边栏底部 AnimatedThemeToggler 调 setTheme 锁定 light/dark；index.html 内联脚本在 React 挂载前读 localStorage(infinite-canvas:theme_store) 的 mode + 系统偏好给 <html> 挂 .dark，避免首屏闪主题；画布底部工具栏外观弹层与画布侧栏底部均不渲染主题切换按钮</span>


14. **<span style="font-size:18px;color:#fff">深色模式下页面大背景不用接近纯黑的颜色，用深灰，比侧边栏稍深一点保持层次；画布那块的点状网格背景，颜色跟生图页卡片的灰色保持一致，别比卡片更深。</span>**<br>

15. **<span style="font-size:18px;color:#fff">模型选择框里的名称和图标要跟着页面的明暗变化：深色页面用浅色文字，浅色页面用深色文字，不能出现黑字落在深色底上看不清。生图、视频和画布里共用的模型选择框都按这个规则显示。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">src/canvas/components/model-picker.tsx 的 SelectTrigger 显式设置 text-text，绑定 src/index.css 的 --color-text：dark 为 #e0e0e0，light 为 #1d1d1f。模型名称及使用 currentColor 的 Cpu、Clapperboard 图标继承该颜色；图片图标保留现有 dark:invert。不得只设置背景而依赖外层默认文字色。修改后检查明暗主题、模型名称和图标可读性；本次 npx tsc -b 与 npx vite build --outDir .deploy-dist 已通过，浏览器视觉确认待完成。</span>


- 统一顶部栏由 AppLayout 占据实际布局高度，页面不得再添加用于避让顶部栏的空白占位块。
- 图像页保留生图、融图、图片翻译子标签；页面外层提供顶部间距，标签栏不再重复添加顶部间距。
- 影像、画布、资产、收藏和团队页不得用空白块对齐其他页面的标签栏。
- 新增或修改公共顶部栏时，检查全部子页面的占位和间距，避免只修复单个页面。
- 首页搜索只在首页展示，同一组搜索和会员等公共入口不在页面内部重复渲染。
- 顶部搜索框以外层背景变化表示焦点，不给内部输入框添加描边；空输入框获得焦点后仍保留提示文字。
- “我的”入口放在顶部栏“会员中心”右侧，登录入口和账户菜单跟随该按钮展开。
- 顶部文字 logo 始终显示；侧栏收起只影响左侧导航内容，不隐藏品牌文字。
- 侧栏收起宽度固定为 56px，展开宽度固定为 148px；收起时导航图标背景保持 30px 正圆并与左右内间距对称，展开时选中背景左右各保留 8px；图像页标签栏左边缘与下方设置面板左边缘对齐，只有第一个标签选中时才去掉面板左上圆角，切换到其他标签时恢复圆角。
- 图像页未选中的子标签悬浮时只提高文字亮度，不添加底色；面板圆角只按选中标签处理，不随悬浮状态变化，非首个标签页面的左上圆角使用较小半径以弱化切换缺口。
- 全局字体由 `src/index.css` 统一管理，画布模块不得在运行时修改 `body` 字体，避免页面异步加载后文字大小和粗细跳变。
- 画布全局主题不得自引用 `--font-sans`，避免异步加载后 `font-sans` 工具类失效并回退到另一套字体。
- 主站字体使用独立的 `--app-font-family` 变量，并锁定 `html`、`body` 的字体；画布懒加载样式不得覆盖全局字体。
- 画布使用 Ant Design 时不得直接引入 `antd/dist/reset.css` 全局重置；Tailwind 基础层已提供通用重置，避免 Ant reset 在单页切换后覆盖主站按钮的字号、行高和颜色。
- 图像页左侧设置卡片与公共侧栏之间只保留 8px 外间距，页面外层收窄左侧 padding 时不得改变侧栏宽度或卡片内部间距。
- 全局模型选择器统一等待服务端模型配置完成后再显示；没有可用模型时显示“暂未获取到模型”，不得先显示本地默认模型再被远程列表替换。
- 模型下拉浮层统一使用比卡片略亮的深色背景，保证列表和页面背景有清晰层次；视频页的 Portal 浮层也必须同步这个颜色。
- 前端不得内置示例模型作为可选项；模型名称只能来自服务端配置，服务端未返回时统一显示“暂未获取到模型”。
- 主题默认跟随系统深浅色；左边栏底部月亮/太阳按钮可手动切浅色/深色并记住选择；画布底部工具栏外观弹层与画布侧栏底部不放主题切换入口；首屏由 index.html 内联脚本提前挂 .dark，避免闪主题。
- 深色模式页面大背景用深灰 #141416（不用接近纯黑的 #09090b），比侧边栏 #151515 稍深保持层次；画布点状网格背景用 #202020，与生图页卡片灰色一致。
- 共用模型选择框必须显式使用主题文字色 text-text；名称和使用 currentColor 的图标随明暗主题变化，图片图标保留现有主题适配，避免深色背景上出现黑字或暗图标。
