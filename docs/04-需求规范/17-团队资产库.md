# 团队资产库

### 这是什么
团队里的共享素材库。成员把自己的图、模板上传到团队资产库，其他成员就能直接用，不用互相发文件。

### 用户怎么用
1. 用户加入团队，进入团队空间看到"资产库"标签
2. 点"上传到资产库"把自己的图传上去
3. 传上去后团队其他成员都能在资产库里看到
4. 成员可以把资产库里的图拖到画布里用
5. 管理员可以删除不合适的素材

### 业务规则
- 只有团队成员能看到团队资产库
- 任何人都可以上传，上传后归团队所有
- 上传者不能单方面删除别人正在用的素材，要管理员删
- 个人空间资产不会自动进团队库，必须手动分享
- 成员退出团队后，他上传的素材还留在团队库里

### 出问题怎么办
素材被乱传，管理员后台审核删除。
