> 来源：线上 `qingyu_business` 的 `app` schema。本文记录当前真实字段，不替代迁移文件；新增字段必须先写迁移，再更新本文。字段名和类型是数据库事实，中文用途说明中“推断”表示需要业务评审。

### 这是什么
纯技术参考：每张表每个字段叫什么、什么类型、能不能空、干嘛用的。

### 用户怎么用
给开发和 AI 查表用，改字段前先看这个。

### 现在长什么样
已导出 99 张表 934 个字段，以后改表必须同步更新。
## 数据分层

- **用户与安全**：账号、设备、会话、同意和安全事件。
- **空间与多租户**：个人空间、团队空间和组织成员关系。所有业务数据必须沿 `workspace_id` 或专用授权关系隔离。
- **订阅与计费**：套餐、订单、支付、订阅、退款、发票。支付事实不能用前端状态代替。
- **额度与用量**：预占、结算、释放、流水和对账。余额是可重算结果，流水才是事实。
- **内容与生成**：生成任务、结果、资产、文件、收藏、点赞和评论。
- **平台运维**：模型目录、渠道、备份、恢复、管理员和系统设置。

## 字段约定

| 列 | 含义 |
|---|---|
| 表 | PostgreSQL 表或视图名 |
| 字段 | 数据库真实列名，代码中保持一致 |
| 类型 | PostgreSQL 信息架构返回类型 |
| 可空 | YES 表示允许 NULL；NO 表示必须有值 |
| 默认值 | 数据库默认表达式；空白表示没有默认值 |
| 用途 | 通俗解释；未建立专门说明时按字段名归纳，标注“推断” |
