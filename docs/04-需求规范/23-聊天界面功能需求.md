# 聊天界面功能需求

### 这是什么

跟 AI 聊天的整个界面要做到什么程度：发消息、看回复、改消息、传图片、用快捷指令，这些日常聊天里该有的功能都要有，跟主流聊天产品用起来一样顺手。


### 用户怎么用


#### 一、消息操作


**1. AI 回复得不好，可以让它重新写一遍**

每条 AI 回复下面有个刷新按钮，点一下，AI 就把刚才那条回答重新生成一遍，不用你把问题再打一次。


**2. AI 还在打字的时候，可以随时叫停**

AI 正在往外蹦字的时候，发送按钮会变成一个方块停止按钮。点一下，AI 立刻闭嘴，不再继续输出。已经出来的内容保留，不会清空。


**3. 自己发出去的消息，发错了能改**

自己发的那条消息旁边有个编辑按钮，点一下就能改字。改完重新发，AI 会根据改过的内容重新回复。原来那条回复会被替换掉。


**4. AI 答得好或不好，可以点个赞或点个踩**

每条 AI 回复下面有个大拇指向上和向下的按钮。点赞就是"答得好"，点踩就是"答得不好"。再点一下可以取消。这个反馈会攒起来，以后用来优化模型。


#### 二、内容展示


**5. AI 回复里的标题、列表、加粗，要排版好看**

AI 回复不能是一坨纯文字。要能识别 Markdown 格式：标题变大加粗、列表有圆点、重要的字加粗、代码单独一块。就跟你在 GitHub 上看 README 一样好看。


**6. 代码要带颜色高亮，还能一键复制**

AI 回复里如果有代码块，不同的编程语言关键字要显示不同颜色。代码块右上角有个复制按钮，点一下整段代码就复制到剪贴板了。


**7. AI 回复要一个字一个字往外蹦，不是等半天一下子全出来**

你发完消息，AI 不是等几秒钟然后突然蹦出一大段话。是像人打字一样，一个字一个字实时往外蹦，你看着它写。这样你不用干等，看到一半觉得方向不对就能打断。


**8. 聊天里能发图片、看图片**

你可以往聊天里发图片。AI 回复里也能带图片，图片能点击放大看。发过的图片在消息里显示成小缩略图，点一下能全屏预览。


#### 三、输入增强


**9. 图片可以直接拖进输入框，不用点按钮**

电脑里的图片文件，直接用鼠标拖到聊天输入框里，松手就传上去了。不用非得点那个加号按钮再去文件夹里选。


**10. 输入 @ 能引用画布上的东西**

在输入框里打个 @ ，会弹出来一个列表，列出你画布里的图、文字、节点。选一个，它就变成一个小标签插进你的消息里。AI 回复的时候就能看到你引用的那个东西。


**11. 常用的话可以存成快捷指令，一键插入**

有些话你天天发，比如"帮我把这个图改成蓝色"。可以把它存成一个快捷指令。下次打个斜杠 / ，选一下，整句话就自动填进输入框里了。不用每次都重新打。


**12. 输入框右下角能看到打了多少字**

输入框里打了多少个字，右下角有个小字实时显示。打多了心里有数，知道是不是太长了。



### 现在长什么样

项目里有两处聊天界面，完成度不一样：

| 功能 | 画布内嵌 AI | 独立聊天页 |
|---|---|---|
| 重新生成 AI 回复 | 已完成 | 未做 |
| 停止生成 | 已完成 | 未做 |
| 编辑已发送消息 | 未做 | 未做 |
| 点赞点踩反馈 | 未做 | 未做 |
| Markdown 渲染 | 已完成（用 Streamdown） | 未做（纯文字） |
| 代码块高亮 | 已完成（Streamdown 自带） | 未做 |
| 流式输出 | 已完成（逐字输出） | 未做（假数据） |
| 图片消息 | 已完成 | 未做 |
| 拖拽上传 | 未做（只有点按钮和粘贴） | 未做 |
| @提及引用 | 已完成（@画布元素、/技能） | 未做 |
| 快捷指令模板 | 未做 | 未做 |
| 字数统计 | 未做 | 未做 |

简单说：画布里面那个 AI 聊天已经挺能用了，独立聊天页还是个空壳。这份需求两边都要满足，已完成的功能两边体验要保持一致。



### 业务规则


**消息操作类**


1. **<span style="font-size:18px;color:#fff">重新生成的时候，原来那条 AI 回复会被替换掉，不会多出一条。你点几次刷新就换几次，聊天记录里始终只有最新那一条。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">onRegenerate 回调传入 messageId，前端替换对应消息内容；调用后端重新生成接口，流式覆盖原消息 streamId；不新增消息节点</span>


2. **<span style="font-size:18px;color:#fff">只有 AI 回复已经写完了，才能点重新生成。正在打字的时候，刷新按钮不出现。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">item.streamId 存在时隐藏操作栏；streamId 为 undefined 时才显示 regenerate/copy 按钮</span>


3. **<span style="font-size:18px;color:#fff">点停止生成之后，已经出来的文字保留在聊天记录里，不会消失。发送按钮变回正常，可以继续发下一条。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">onStop 调用 AbortController.abort() 终止 SSE 流；保留已接收的 text 内容；sending 状态置为 false，恢复发送按钮</span>


4. **<span style="font-size:18px;color:#fff">编辑自己发的消息，改完重新发之后，原来那条 AI 回复会被删掉，AI 根据你改后的问题重新答一条。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">用户消息进入编辑态（textarea 替换纯文本）；确认后删除该 user message 之后的所有 assistant 消息，用新内容重新调流式接口</span>


5. **<span style="font-size:18px;color:#fff">点赞和点踩不能同时选，点了赞再点踩，赞自动取消。再点一下当前选的，就取消反馈。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">feedback 状态枚举：null | up | down；互斥切换；重复点击置回 null；上报后端 /api/feedback 记录 messageId + rating</span>


6. **<span style="font-size:18px;color:#fff">只有 AI 的回复能点赞点踩，自己发的消息不行。正在打字的时候也不显示。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">仅 role === 'assistant' 且无 streamId 时渲染 feedback 按钮组</span>


**内容展示类**


7. **<span style="font-size:18px;color:#fff">Markdown 渲染用现成的组件库，不用自己写解析。代码块、表格、链接这些常见格式都要正常显示。点外部链接的时候要弹确认框，防止不小心跳到不安全的网站。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">使用 Streamdown 组件（已在项目中引入）；linkSafety.enabled = true；自定义 AgentLinkModal 确认外部链接跳转；支持 GFM 表格、代码块、列表</span>


8. **<span style="font-size:18px;color:#fff">代码块右上角有复制按钮，点一下复制整段代码，弹个提示说"已复制"。不用手动选文字。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">Streamdown controls.code.copy = true；navigator.clipboard.writeText；App.useApp().message.success 弹 toast</span>


9. **<span style="font-size:18px;color:#fff">流式输出的时候，文字一个字一个字出来，带着打字动画。打完之后动画停住，内容固定下来。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">SSE / fetch ReadableStream 逐 chunk 追加 text；Streamdown animated={{ duration: 20, sep: 'word' }}，isAnimating = !!streamId；streamId 清空后停止动画</span>


10. **<span style="font-size:18px;color:#fff">图片消息显示成小缩略图，点一下能放大看大图。大图可以左右切换看其他图。</span>**<br>
    <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">attachments 数组渲染 size-10 缩略图；antd Image preview 实现全屏预览；preview.images 支持多图切换</span>

11. **<span style="font-size:18px;color:#fff">把图片文件从电脑桌面或文件夹里，直接拖到聊天输入框区域，松手就上传成功了。拖进来的时候输入框会高亮告诉你"放到这儿就行"。</span>**<br>

12. **<span style="font-size:18px;color:#fff">在输入框里打个 @ 号，会弹出来一个列表，列出画布里的图、文字、节点。用上下箭头选，回车确认。选完之后 @ 会变成一个小标签，不是纯文字。</span>**<br>

13. **<span style="font-size:18px;color:#fff">打个斜杠 / 号，能弹出你存过的快捷指令。选一个，整句话就自动填进输入框里。快捷指令自己可以加、可以删。</span>**<br>
    <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">/(^|\s)\/([^\/\s]*)$ 检测触发；快捷指令存 localStorage 或后端 user_preferences；{ name, prompt } 结构；选中后 insertTextAtCaret 填入 prompt 全文</span>


14. **<span style="font-size:18px;color:#fff">输入框右下角实时显示当前打了多少个字。没打就不显示，打了就显示个小灰字。超过上限了数字变红。</span>**<br>

### 出问题怎么办


- **重新生成失败** → 弹 toast 提示"重新生成失败，请重试"，原来的回复保留不删

- **停止生成没反应** → 检查网络是否断了，刷新页面后已输出内容仍在

- **编辑消息后 AI 回复丢了** → 这是正常的，改了问题就相当于重问，旧答案作废

- **图片拖进去没反应** → 确认拖的是图片文件（png/jpg/webp），拖文件夹不支持；大文件（超过 10MB）会提示太大

- **@ 列表弹不出来** → 确认画布里有内容，空画布没有可引用的东西

- **Markdown 渲染乱了** → 检查 AI 返回的格式是不是标准 Markdown，特殊符号可能需要转义



### 花多少钱

前端渲染、交互、拖拽这些全是浏览器里跑，不花服务器钱。流式输出和 AI 回复本身的费用跟现有 AI 对话一样，走已有的计费逻辑。点赞点踩存到数据库，量很小，不额外花钱。



### AI 对照

**可复用的已有实现：**

| 功能 | 已有组件/文件 | 说明 |
|---|---|---|
| Markdown + 代码高亮 | `Streamdown`（agent-chat-message.tsx） | 直接复用，已配好代码复制、链接安全弹窗 |
| 流式输出 | SSE + streamId（use-agent-store） | ChatPage 现在是 setTimeout 假数据，要接真实流式接口 |
| @提及引用 | agent-chat-prompt-input.tsx | 已有 @ 画布元素和 / 技能两套触发，快捷指令可参考这套交互 |
| 图片消息 | AgentMessageAttachments | 缩略图 + antd Image 预览，直接抽成公共组件 |
| 停止生成 | AgentChatComposer onStop | AbortController 模式，复用 |
| 重新生成 | AgentChatMessage onRegenerate | RefreshCw 按钮 + 回调，复用 |

**需要新做的：**

| 功能 | 工作量 | 关键点 |
|---|---|---|
| 编辑已发送消息 | 中 | 消息切编辑态 + 删除后续消息 + 重发 |
| 点赞点踩反馈 | 小 | 两个图标按钮 + 互斥状态 + 上报接口 |
| 拖拽上传 | 小 | 输入框区域加 drag/drop 事件，复用 onAddFiles |
| 快捷指令模板 | 中 | 存储 + / 触发列表 + 插入逻辑 |
| 字数统计 | 极小 | 右下角加个字数显示 |
| ChatPage 整体改造 | 大 | 从假数据改成接真实流式接口 + 接公共消息组件 |

**技术栈参考：**

- 消息渲染：Streamdown（已引入，不要换别的库）
- 图标：lucide-react（项目统一用这个）
- 反馈提示：antd App.useApp() 的 message（项目统一 toast）
- 图片预览：antd Image
- 流式请求：fetch ReadableStream 或 EventSource
