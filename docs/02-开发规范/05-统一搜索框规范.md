# 统一搜索框规范

## 规矩

1. **<span style="font-size:18px;color:#fff">全站所有搜索框（首页那个除外）一律用同一个组件，不要各页面自己写 input。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">统一组件文件：src/components/SearchInput.tsx。禁止在页面里直接写 &lt;input placeholder="搜索"&gt;、antd &lt;Input.Search&gt; 或带 Search 图标的裸 input。首页搜索框（WorkbenchPage / AppLayout 里的全局搜索）暂不在本规范范围内，保持现状。</span>


2. **<span style="font-size:18px;color:#fff">放在顶栏、工具条上的搜索框，平时只露一个放大镜图标；鼠标放上去才向右展开成输入框；鼠标移开且里面没字的时候，自动收回去只留图标。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">组件 mode="collapsible"。收起态尺寸 30×30，展开态宽度 200px，圆角 8px，背景 bg-input。展开时自动 focus 输入框；onBlur 延迟 150ms 后若 value 为空则收回（延迟是为了让点清除按钮的操作先生效）。展开动画 transition-all 200ms ease-out。</span>


3. **<span style="font-size:18px;color:#fff">放在弹窗里、侧边面板里、或者页面中间当主要功能的搜索框，就一直显示输入框，不要做收起动画。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">组件 mode="expanded"。常显输入框，左侧 16px 放大镜图标，右侧带清除按钮（有内容时显示 X）。已统一位置：Canvas 资产页、Canvas Prompts 页、Canvas 侧边面板（节点/资产/Prompt 三处）、模型选择弹窗、Prompt 选择弹窗、Agent 技能列表。</span>


4. **<span style="font-size:18px;color:#fff">搜索框不要加描边，背景用统一的 input 色，聚焦时只亮一圈淡色光晕，不要实线边框。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">背景 bg-input，圆角 8px；聚焦态 focus-within:ring-1 focus-within:ring-accent，outline: none，border: none。遵循全局"禁止描边"规则。</span>


5. **<span style="font-size:18px;color:#fff">搜索框里输入字之后，即使鼠标移开也不要收回去；只有把字清空了、或者点了清除按钮，才收回去。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">collapsible 模式下，onBlur 时判断 value 是否为空：空则收起，非空保持展开。有内容时右侧显示 X 清除按钮，点清除后自动 focus 回输入框。</span>


6. **<span style="font-size:18px;color:#fff">搜索框展开后自动聚焦，用户可以直接打字，不用再点一下。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">collapsible 模式 hover 展开后通过 requestAnimationFrame 里调 input.focus()。</span>


7. **<span style="font-size:18px;color:#fff">每个页面的搜索框搜什么，由那个页面自己决定，组件不管。组件只管外观和交互。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">组件 props：value(string)、onChange(value: string)、placeholder?、mode?（默认 collapsible）、className?、disabled?。业务过滤逻辑由使用页面自己实现。图片工具页搜生成历史的 prompt 字段；资产页搜资产 name；Canvas 资产页按 keyword 过滤资产列表。</span>


8. **<span style="font-size:18px;color:#fff">搜索框的放大镜图标大小、文字字号、占位符颜色，全站统一，不要在页面里单独调。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">图标 lucide Search：collapsible 态 14px、expanded 态 16px，颜色 text-muted。输入文字：collapsible 态 13px、expanded 态 14px，颜色 text；placeholder 颜色 text-muted。disabled 时整体 opacity-50、cursor-not-allowed。这些写死在组件里，页面不覆盖。</span>


9. **<span style="font-size:18px;color:#fff">图片工具页原来那个放大镜按钮是假的（点了只弹 toast），现在换成了真搜索框，按提示词过滤生成历史记录。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">ImageToolsPage.tsx：新增 searchKeyword state，filteredResults = results.filter(r => r.prompt.includes(searchKeyword))，原来的 results.map 全部换成 filteredResults.map。</span>
