# 语音输入开发规范

### 这是什么

项目里所有输入框旁边的麦克风按钮，点一下说话，字自动填进去。纯前端本地识别，不用接 AI、不花钱。

### 组件在哪

1. **<span style="font-size:18px;color:#fff">麦克风按钮组件在 `src/components/speech-input-button.tsx`，直接用就行，不用自己画。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">SpeechInputButton 组件，接收 onResult 回调，识别完成后把文本传回来</span>


2. **<span style="font-size:18px;color:#fff">语音识别的逻辑在 `src/lib/use-speech-input.ts`，封装好了开始、停止、状态管理。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">useSpeechInput hook，基于 speech-asr npm 包，底层是 sherpa-onnx WebAssembly</span>


3. **<span style="font-size:18px;color:#fff">模型文件放在 `public/models/sherpa-onnx-wasm-asr-1pass/`，不要改位置，改了就加载不了。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">模型文件约 280MB，包含 sherpa-onnx-wasm-main-asr.data / .js / .wasm 等文件</span>

### 新页面怎么接

4. **<span style="font-size:18px;color:#fff">新页面要加语音输入，只要 import 组件，然后在输入框旁边放一个按钮就行。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">import { SpeechInputButton } from '@/components/speech-input-button'; 然后在 JSX 里放 <SpeechInputButton onResult={(text) => setInput(prev => prev + ' ' + text)} /></span>


5. **<span style="font-size:18px;color:#fff">识别出来的字是追加到输入框后面，不是替换原来的内容。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">onResult 回调里拿到 text，然后 setInput(prev => prev + ' ' + text)，空格分隔</span>


6. **<span style="font-size:18px;color:#fff">AntD 的 Input.TextArea 可以用 suffix 属性把按钮放在输入框里面。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1"><Input.TextArea suffix={<SpeechInputButton ... />} />，原生 textarea 就用绝对定位放在右下角</span>

### 注意事项

7. **<span style="font-size:18px;color:#fff">按钮样式用 `text-text-secondary` 类，浅色暗色都能自动适配，不要写死颜色。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">className="text-text-secondary"，跟随项目主题，不要用 inline style 写死颜色</span>


8. **<span style="font-size:18px;color:#fff">第一次点按钮会加载模型，按钮会转圈，这是正常的，不是卡死。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">模型约 280MB，首次加载需等待，加载完浏览器缓存，以后秒开</span>


9. **<span style="font-size:18px;color:#fff">密码框、API Key 这些敏感输入框不要加语音输入。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">Input.Password 等敏感字段不加麦克风，避免隐私风险</span>


10. **<span style="font-size:18px;color:#fff">麦克风权限被拒绝时会静默失败，用户需要去浏览器设置里开权限。</span>**<br>
    <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">getUserMedia 权限拒绝时浏览器会弹窗提示，用户允许后才能用</span>
