# AI 对话管理

### 这是什么

在 AI 对话页（顶部导航点"对话"进去的那个页面）左边加一条历史对话栏。你以前跟 AI 聊过的每一段对话都自动存在自己浏览器里，刷新网页不会丢；想重新聊就点"+"新开一段，想接着上次聊就点列表里旧的那一段，名字不顺眼可以改，不要的可以删掉。

> 注意：这跟画布右边那个小怪兽 Agent 面板里的"历史线程"是两码事。小怪兽连的是你自己电脑上的开发助手，跟这里是两套东西，别混。

### 用户怎么用

1. 打开 AI 对话页，左边就是一条历史对话列表，右边是聊天内容
2. 点列表顶部的"+ 新建对话"，开始一段全新的对话
3. 点列表里任意一条，右边聊天区立刻切到那段对话的历史消息，可以接着聊
4. 鼠标移到某一条对话上，会冒出两个小按钮：铅笔是改名，垃圾桶是删除
5. 点垃圾桶会先弹一个确认框，问你"确定删除吗"，确认了才真删
6. 左边那条栏可以收起来，收起来以后聊天区变宽；想再看列表，点一下展开按钮就回来

### 现在长什么样

还没开始做。

当前对话页是个空壳：发消息后假等 0.4 秒，回一句"网页端对话服务待接入"；消息只临时存在网页内存里，一刷新就全没了；页面上没有任何"第几次聊"的概念，也没有左边这条历史栏。

下一步：先做本地存储和左侧栏骨架，把新建、列表、删除、重命名四个动作做通；AI 真正回复的功能以后再接。

### 业务规则

1. **<span style="font-size:18px;color:#fff">对话和消息都存在你自己的浏览器里，不上传到网站服务器。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">使用 localforage（IndexedDB）持久化，storeName 独立于现有 infinite-canvas 库；不调用任何后端接口，不写 api-server.mjs；后续接真 AI 对话时再考虑迁移到 PostgreSQL</span>

2. **<span style="font-size:18px;color:#fff">打开页面的时候自动把你上次的对话恢复出来，不用手动找。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">页面挂载时从 localforage 读取全部对话列表，按 updatedAt 倒序排序，自动选中最近更新的一条并渲染其 messages；localStorage 里记一个 activeConversationId，下次打开优先恢复它</span>

3. **<span style="font-size:18px;color:#fff">第一次用的时候一条对话都没有，左边列表是空的，中间显示大欢迎语，直接打字就能开始。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">conversations 为空时不自动造空对话，右侧保留现有空状态（大标题"有什么可以帮你？"+ 副标题）；用户发出第一条消息时才真正创建一条对话记录</span>

4. **<span style="font-size:18px;color:#fff">点"+ 新建对话"立刻切到一个干净的聊天界面，输入框清空，之前聊的内容不动。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">createConversation() 生成一条 title="新对话"、messages=[]、createdAt/updatedAt=Date.now() 的记录并设为 active；立即写入 localforage；切过去后 input、sending 状态重置</span>

5. **<span style="font-size:18px;color:#fff">对话列表按最近聊过的时间从新到旧排，最新聊过的永远在最上面。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">每条对话的 updatedAt 在发消息、改名时刷新；列表渲染前按 updatedAt 降序 sort；点列表项切换时只改 activeId，不重排</span>

6. **<span style="font-size:18px;color:#fff">每条对话显示标题和一个相对时间，比如"刚刚""5 分钟前""昨天""3 天前"。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">标题 14px 截断单行；时间 11px 灰色，按 dayjs.fromNow 类相对格式化：<1 分钟"刚刚"，<60 分钟"N 分钟前"，<24 小时"N 小时前"，昨天显示"昨天 HH:mm"，更早显示"MM-DD"</span>

7. **<span style="font-size:18px;color:#fff">正在看的这条对话在列表里高亮，一眼知道自己在跟谁聊。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">activeId === item.id 时该项背景用 raise 色（--raise），非 active 项透明；不用左边竖条、不用 border，靠背景色区分</span>

8. **<span style="font-size:18px;color:#fff">你发出第一条消息以后，对话标题自动用这句话的前 20 个字，省得你自己起名。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">当 conversations 中该条 messages 为空、用户首次发送 user 消息时，取 user.content.trim().slice(0,20) 作为 title；超过 20 字加"…"；用户手动改过名以后就不再自动覆盖（用 renamed: true 标记）</span>

9. **<span style="font-size:18px;color:#fff">想改名就点铅笔，弹一个小窗输入新名字，回车或点保存生效。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">antd Modal 居中弹窗，Input 自动聚焦并全选原标题，最大 40 字；点确定或 Enter 触发 renameConversation(id, newTitle)；空字符串或纯空白不保存、保留原名；保存成功 message.success("已重命名")</span>

10. **<span style="font-size:18px;color:#fff">删除对话前必须先弹确认框，告诉你这条对话有多少条消息，点"删除"才真删，点"取消"什么都不发生。</span>**<br>
    <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">antd Modal.confirm，标题"删除对话"，内容"确定删除「标题」吗？该对话的 N 条消息将无法恢复。"，按钮 danger 风格；onOk 才调用 deleteConversation(id)；删除成功 message.success("已删除")</span>

11. **<span style="font-size:18px;color:#fff">如果你删的正是当前正在看的那条，删完自动切到列表里剩下的第一条；如果全删光了，就回到欢迎页空状态。</span>**<br>
    <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">deleteConversation 后若被删 id === activeId，从剩余 conversations 里取 updatedAt 最新一条设为 active；剩余为空则 activeId=""、messages=[]，右侧显示欢迎大标题</span>

12. **<span style="font-size:18px;color:#fff">新建、切换、改名、删除这几个动作做完都有 toast 提示，不会默默操作。</span>**<br>
    <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">统一用 antd App.useApp() 的 message：新建成功不弹（界面已切换，够明显）；重命名成功"已重命名"；删除成功"已删除"；失败（localforage 写入异常）message.error("操作失败，请重试")</span>

13. **<span style="font-size:18px;color:#fff">左边这条栏可以收起来，收起来以后聊天区变宽；展开按钮在左上角，不管侧栏开还是关都能点到。</span>**<br>
    <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">侧栏宽 260px，收起后宽 0，右侧聊天区 flex-1 自动占满；折叠状态存 localStorage("chat-sidebar-collapsed")；展开按钮用 PanelLeft/PanelRight 图标，34×34 透明按钮 hover 变亮</span>

14. **<span style="font-size:18px;color:#fff">鼠标移到某条对话上才显示铅笔和垃圾桶两个小按钮，平时不显示，列表干净。</span>**<br>
    <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">操作按钮组默认 opacity:0，父项 hover 时 opacity:1 transition .15s；两个按钮都是 24×24 圆形透明底，hover 变 raise 背景；删除按钮 hover 时图标变红</span>

15. **<span style="font-size:18px;color:#fff">整个页面不描边、不加边框，靠背景色深浅区分层级，跟网站现在的暗色风格统一。</span>**<br>

### 出问题怎么办

* 刷新网页后对话没了 → 检查是不是用了无痕/隐私模式，或者手动清过浏览器站点数据；这个功能数据存在本地，清缓存会一起清掉
* 对话列表里有一条点不动、名字灰色 → 那是本地存储写入失败，通常是浏览器磁盘满了，删几条旧对话腾地方
* 删错了一条对话 → V1 没有回收站，删了就找不回来；删除前确认框会写清楚"无法恢复"，以后版本再加回收站
* 换了台电脑/换了浏览器发现以前的对话都不在 → 正常，V1 只存在当前浏览器；等接了账号云同步才会跟着账号走
