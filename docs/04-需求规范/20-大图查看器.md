# 大图查看器

### 这是什么

点任何一张图片，都能全屏放大看。看大图的时候可以滚轮放大缩小、拖来拖去、左右切上一张下一张，底部还显示现在放大了百分之多少。全站所有地方看图都长一个样。

### 用户怎么用

1. 在任何地方点图片（生图结果、素材、聊天附件、画布参考图……），屏幕变黑，图片居中放大

2. 鼠标滚轮往上滚是放大，往下滚是缩小，底部实时显示现在是百分之多少（比如 200%）

3. 放大了以后按住鼠标可以拖动图片看细节

4. 点左右两个箭头按钮，或者按键盘左右方向键，切上一张/下一张

5. 点空白处、按 ESC、或者点右上角 X，关闭大图

### 现在长什么样

已经做完了。统一的看图组件接好了以下地方：
- 图片工具页（生图结果、参考图缩放按钮）
- 图片翻译页（原图和翻译结果图，多图可左右切）
- 画布节点参考栏（上传的参考图）
- 画布项目页节点详情（原来只能看不能缩放，现在能缩放拖动）

点任何一张图都能全屏放大，滚轮缩放、拖动细节、左右箭头或键盘方向键切上一张下一张、底部显示缩放百分比、ESC 或点空白关闭。只有一张图的时候左右箭头自动藏起来。

图片翻译页的原图缩略图：鼠标悬浮时底部浮现两个按钮（重新上传、删除），下面显示文件大小和分辨率（如 924.8 KB · 1080x1920），文件名后缀自动大写。右边翻译结果图只有刷新和下载按钮，不显示删除。

### 业务规则

1. **<span style="font-size:18px;color:#fff">全站只有一个看图组件，所有地方点图片都用它，不会出现不同地方看图体验不一样的情况。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">新建 `src/components/ImageViewer.tsx`，接收 images 数组和 currentIndex，替换 ImageToolsPage、canvas-node-reference-bar、canvas/project.tsx 里的手写查看器和简陋 Modal</span>

2. **<span style="font-size:18px;color:#fff">滚轮缩放范围从 50% 到 800%，不能缩到看不见也不能放大到糊掉。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">zoom clamp(0.5, 8)，onWheel deltaY 判断方向，步长 0.2</span>

3. **<span style="font-size:18px;color:#fff">只有放大到超过 100% 的时候才能拖图片，原始大小拖不动，防止误操作。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">onMouseDown 时判断 zoom > 1 才启动拖拽，带惯性衰减 decay=0.92</span>

4. **<span style="font-size:18px;color:#fff">底部居中显示缩放百分比，跟手机相册看图一样，一眼知道现在放大了多少。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">fixed bottom-8 left-1/2 -translate-x-1/2，显示 Math.round(zoom*100)%</span>

5. **<span style="font-size:18px;color:#fff">左右箭头按钮在屏幕两边，键盘左右方向键也能切。只有一张图的时候箭头自动藏起来。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">images.length > 1 时渲染左右按钮，index 边界 clamp 不循环；keydown 监听 ArrowLeft/ArrowRight</span>

6. **<span style="font-size:18px;color:#fff">关闭大图的时候缩放和位置自动复位，下次打开又是从 100% 居中开始。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">onClose 时重置 zoom=1、pan={x:0,y:0}</span>

7. **<span style="font-size:18px;color:#fff">点图片本身不关闭大图，点图片外面的黑色遮罩才关。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">img onClick stopPropagation，遮罩 onClick 关闭</span>

8. **<span style="font-size:18px;color:#fff">弹窗用 createPortal 渲染到 body 最外层，不会被画布、侧边栏这些东西挡住。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">createPortal to document.body，z-index 9999</span>

### 出问题怎么办

* 点图片没反应 → 检查图片 URL 是否加载成功，网络慢时先显示 loading
* 放大后拖不动 → 确认 zoom > 1，zoom=1 时禁用拖拽
* 左右切图没反应 → 确认传入了 images 数组且 length > 1
* ESC 关不掉 → 确认组件挂载时绑定了 keydown，卸载时移除
