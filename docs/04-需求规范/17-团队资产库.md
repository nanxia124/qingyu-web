# 团队资产库

### 这是什么
团队里的共享素材库。成员把自己的图、模板上传到团队资产库，其他成员就能直接用，不用互相发文件。

### 用户怎么用
1. 用户加入团队，进入团队空间看到"资产库"标签
2. 点"上传到资产库"把自己的图传上去
3. 传上去后团队其他成员都能在资产库里看到
4. 成员可以把资产库里的图拖到画布里用
5. 管理员可以删除不合适的素材

### 业务规则

1. **<span style="font-size:18px;color:#fff">团队资产库只有本团队成员能看到和使用，非团队成员看不到里面的内容。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">只有团队成员能看到团队资产库</span>


2. **<span style="font-size:18px;color:#fff">任何团队成员都可以上传图片，上传后这张图归团队所有，不再属于上传者个人。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">任何人都可以上传，上传后归团队所有</span>


3. **<span style="font-size:18px;color:#fff">如果你上传的图正被其他成员使用，你不能直接删除；需要删除时找管理员处理，避免其他成员的画布出现空缺。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">上传者不能单方面删除别人正在用的素材，要管理员删</span>


4. **<span style="font-size:18px;color:#fff">你个人空间里的图不会自动进入团队资产库，必须手动点"上传到资产库"才会进去。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">个人空间资产不会自动进团队库，必须手动分享</span>


5. **<span style="font-size:18px;color:#fff">你退出团队后，之前上传到团队资产库的图继续留在团队里供其他成员使用，不会随你离开。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">成员退出团队后，他上传的素材还留在团队库里</span>

### 出问题怎么办
素材被乱传，管理员后台审核删除。
