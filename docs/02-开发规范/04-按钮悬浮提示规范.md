# 按钮悬浮提示规范

## 规矩

1. **<span style="font-size:18px;color:#fff">凡是按钮需要鼠标悬浮才显示提示的，一律用 antd 的 Tooltip 组件包一层，不要自己写 data-tip，也不要直接在 button 上写 title 属性。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">import { Tooltip } from 'antd'; 用 &lt;Tooltip title="提示文字"&gt;&lt;button&gt;...&lt;/button&gt;&lt;/Tooltip&gt; 包裹。禁止使用 data-tip 属性和原生 button title 属性。</span>

2. **<span style="font-size:18px;color:#fff">Tooltip 的外观全站统一，不要在单个按钮上写死颜色、字号、阴影。统一样式在 src/index.css 里改一次就行。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">全局样式在 src/index.css 的 .ant-tooltip .ant-tooltip-inner 选择器里统一设置：12px 字号、400 字重、6px 圆角、5px 10px 内边距、柔和阴影。禁止在 Tooltip 上传 color、styles 等内联样式。</span>

3. **<span style="font-size:18px;color:#fff">按钮本身已经有文字标签的（比如"下载""删除"这种写在按钮上的），不需要再加 Tooltip，悬浮提示跟按钮文字重复了。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">纯图标按钮必须加 Tooltip；带文字的按钮如果文字已经说明了功能，不需要额外 Tooltip。</span>

4. **<span style="font-size:18px;color:#fff">侧栏导航这种用 NavLink 的链接，也用 Tooltip 包一层，不要用 NavLink 自带的 title 属性。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">NavLink 上的 title={...} 要去掉，改成 &lt;Tooltip title={...}&gt;&lt;NavLink&gt;...&lt;/NavLink&gt;&lt;/Tooltip&gt;。</span>
