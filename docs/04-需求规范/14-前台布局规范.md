# 前台布局规范

### 这是什么
规定网站前台长什么样、间距多大、顶部栏和侧栏怎么摆。

### 用户怎么用
- 顶部固定栏：左边 logo、中间搜索、右边"我的"
- 左侧栏点一下收起成图标，再点展开
- 生图页下面有标签切换，模型下拉框在右边

### 现在长什么样
- ✅ 顶部栏统一、侧栏能收放、模型列表从后端拉
- ❌ 不同屏幕宽度下错位还没全测

1. **<span style="font-size:18px;color:#fff">顶部栏占掉固定高度后，下面的页面内容区不要再加一块空白去避让顶部栏；生图页要分组签，页面内容区顶部自己留一次间距就行，别在标签栏又留一次。别的页面（影像、画布、资产、收藏、团队）也别加空白去对齐生图页那个标签栏。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">统一顶部栏由 AppLayout 占据实际布局高度，页面不得再添加用于避让顶部栏的空白占位块；图像页外层提供顶部间距，标签栏不再重复加；影像/画布/资产/收藏/团队页不得用空白块对齐其他页面标签栏</span>


2. **<span style="font-size:18px;color:#fff">改顶部栏时要把每个子页面都检查一遍间距和对齐，别只改首页就完事。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">新增或修改公共顶部栏时，检查全部子页面的占位和间距，避免只修复单个页面</span>


3. **<span style="font-size:18px;color:#fff">搜索框只在首页放一个，别在每个页面里都重复放一套搜索和会员入口。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">首页搜索只在首页展示，同一组搜索和会员等公共入口不在页面内部重复渲染</span>


4. **<span style="font-size:18px;color:#fff">搜索框被点中时，靠外面整块背景变亮来表示；别给里面那个输入框加一圈描边。空着的时候提示文字也别消失。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">顶部搜索框以外层背景变化表示焦点，不给内部输入框添加描边；空输入框获得焦点后仍保留提示文字</span>


5. **<span style="font-size:18px;color:#fff">"我的"这个入口放在"会员中心"右边，登录和账户菜单都从这个按钮展开。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">"我的"入口放在顶部栏"会员中心"右侧，登录入口和账户菜单跟随该按钮展开</span>


6. **<span style="font-size:18px;color:#fff">顶部的品牌 logo 永远显示；把左边那排导航收起来时，收的只是导航，不是品牌 logo。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">顶部文字 logo 始终显示；侧栏收起只影响左侧导航内容，不隐藏品牌文字</span>


7. **<span style="font-size:18px;color:#fff">左边导航收起来就缩成一条窄窄的图标竖条，展开就变宽；图标排得整整齐齐、左右对称。生图页那排标签要跟下面设置面板左边对齐，只有点第一个标签时面板左上角才是方角，切到别的标签就变回圆角。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">侧栏收起 56px、展开 148px；收起时图标背景 30px 正圆且左右对称，展开时选中背景左右各留 8px；图像页标签栏左边缘与设置面板左边缘对齐，仅首个标签选中时去掉面板左上圆角，切回其他标签恢复圆角</span>


8. **<span style="font-size:18px;color:#fff">鼠标扫过没选中的标签时，只让字变亮一点，别垫一块底色；面板的圆角只看"现在选中哪个"，不跟着鼠标扫来扫去变。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">未选中子标签悬浮只提高文字亮度，不加底色；面板圆角只按选中标签处理，不随悬浮变化；非首个标签页面左上圆角用较小半径弱化切换缺口</span>


9. **<span style="font-size:18px;color:#fff">全站字体由一个地方统一管，别翻页时字突然变大变粗跳一下；也别让某个页面偷偷换了另一套字体。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">全局字体由 src/index.css 统一管理；画布不得运行时改 body 字体，不得自引用 --font-sans；主站用独立 --app-font-family 锁定 html/body，画布懒加载样式不得覆盖；不直接引入 antd/dist/reset.css 全局重置</span>


10. **<span style="font-size:18px;color:#fff">左边设置卡片跟导航条之间只留一小段缝；里面内容挪位置时，别把导航条宽度和卡片内部挤变形。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">图像页左侧设置卡片与公共侧栏之间只留 8px 外间距；页面外层收窄左侧 padding 时不得改变侧栏宽度或卡片内部间距</span>


11. **<span style="font-size:18px;color:#fff">模型下拉框要等服务端把"今天有哪些模型"送来了再摆出来；没送来就老实显示"暂未获取到模型"，别先塞几个假模型凑数再被真清单换掉。也不许偷偷内置示例模型当可选项。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">全局模型选择器统一等待服务端模型配置完成后再显示；没有可用模型显示"暂未获取到模型"，不得先显示本地默认模型再被远程列表替换；前端不得内置示例模型，模型名只能来自服务端配置</span>


12. **<span style="font-size:18px;color:#fff">模型下拉弹出来的那层浮板，用比卡片稍亮一点的深色，让列表和背景分得清；视频页弹出来的浮板也用同一个颜色。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">模型下拉浮层统一使用比卡片略亮的深色背景，保证列表和页面背景有清晰层次；视频页 Portal 浮层也必须同步这个颜色</span>


- 统一顶部栏由 AppLayout 占据实际布局高度，页面不得再添加用于避让顶部栏的空白占位块。
- 图像页保留生图、融图、图片翻译子标签；页面外层提供顶部间距，标签栏不再重复添加顶部间距。
- 影像、画布、资产、收藏和团队页不得用空白块对齐其他页面的标签栏。
- 新增或修改公共顶部栏时，检查全部子页面的占位和间距，避免只修复单个页面。
- 首页搜索只在首页展示，同一组搜索和会员等公共入口不在页面内部重复渲染。
- 顶部搜索框以外层背景变化表示焦点，不给内部输入框添加描边；空输入框获得焦点后仍保留提示文字。
- “我的”入口放在顶部栏“会员中心”右侧，登录入口和账户菜单跟随该按钮展开。
- 顶部文字 logo 始终显示；侧栏收起只影响左侧导航内容，不隐藏品牌文字。
- 侧栏收起宽度固定为 56px，展开宽度固定为 148px；收起时导航图标背景保持 30px 正圆并与左右内间距对称，展开时选中背景左右各保留 8px；图像页标签栏左边缘与下方设置面板左边缘对齐，只有第一个标签选中时才去掉面板左上圆角，切换到其他标签时恢复圆角。
- 图像页未选中的子标签悬浮时只提高文字亮度，不添加底色；面板圆角只按选中标签处理，不随悬浮状态变化，非首个标签页面的左上圆角使用较小半径以弱化切换缺口。
- 全局字体由 `src/index.css` 统一管理，画布模块不得在运行时修改 `body` 字体，避免页面异步加载后文字大小和粗细跳变。
- 画布全局主题不得自引用 `--font-sans`，避免异步加载后 `font-sans` 工具类失效并回退到另一套字体。
- 主站字体使用独立的 `--app-font-family` 变量，并锁定 `html`、`body` 的字体；画布懒加载样式不得覆盖全局字体。
- 画布使用 Ant Design 时不得直接引入 `antd/dist/reset.css` 全局重置；Tailwind 基础层已提供通用重置，避免 Ant reset 在单页切换后覆盖主站按钮的字号、行高和颜色。
- 图像页左侧设置卡片与公共侧栏之间只保留 8px 外间距，页面外层收窄左侧 padding 时不得改变侧栏宽度或卡片内部间距。
- 全局模型选择器统一等待服务端模型配置完成后再显示；没有可用模型时显示“暂未获取到模型”，不得先显示本地默认模型再被远程列表替换。
- 模型下拉浮层统一使用比卡片略亮的深色背景，保证列表和页面背景有清晰层次；视频页的 Portal 浮层也必须同步这个颜色。
- 前端不得内置示例模型作为可选项；模型名称只能来自服务端配置，服务端未返回时统一显示“暂未获取到模型”。
