# 组件导入规范

## 规矩

1. **<span style="font-size:18px;color:#fff">从 antd 用的组件（下拉菜单、弹窗、按钮这些），跟从图标库用的图标，要分两条 import 写，不要混在同一条里。混在一起页面会直接崩，报错说图标库里没有这个组件。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">antd 组件（Dropdown、Modal、Button、Select 等）从 'antd' 导入；lucide-react 图标从 'lucide-react' 导入。两条 import 分开写，不要把 antd 组件名加到 lucide-react 的 import 列表里。</span>
