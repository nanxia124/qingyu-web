# 语音输入

### 这是什么

每个输入框旁边加一个麦克风按钮，点一下说话，字就自动蹦到输入框里。不用打字，说话就行。

### 用户怎么用



1. 输入框右边出现一个小话筒图标

2. 点一下开始说话，边说边出字

3. 说完停两秒，自动确认填进去

4. 说错了直接手动改就行

### 现在长什么样

已经做完了，项目里 15 个页面的输入框都接了麦克风按钮。点一下就能说话，说完自动填到输入框里。第一次用会下载语音模型（约 280MB），下完浏览器缓存，以后秒开。

### 业务规则



1. **所有识别都在你自己的浏览器里完成，声音不会传到我们服务器，也不花一分钱 API 费。**&#x7EAF;前端本地推理，基于 sherpa-onnx WebAssembly，零后端、零 API 调用、零按量计费

2. **第一次用会下载一个语音模型文件（大概几十 MB），下完之后浏览器会缓存，以后再用不用重新下。**&#x6A21;型文件放 public/models/，首次加载后浏览器 HTTP 缓存；中文流式 Zipformer int8 量化版，约 30-100MB

3. **说话的时候字是一个一个实时蹦出来的，不是等你全说完才一次性出。说错的地方可以手动删了重说。**&#x6D41;式识别，onPartial 回调实时返回中间结果；VAD 自动检测停顿分段，说完自动 endpoint 确认

4. **如果浏览器拒绝了麦克风权限，会提示你去浏览器设置里打开，不会静默失败。**&#x67;etUserMedia 权限拒绝时 toast 提示用户检查浏览器权限设置

5. **识别出来的字直接填到输入框里，跟你自己打的字一模一样，后续表单提交、保存逻辑不用改。**&#x901A;过受控组件 onChange 写入 value，复用现有 AntD Input/TextArea 的值绑定和提交流程

6. **这个功能我们可以放心商用，底层代码和模型都是开源允许免费商用的。**&#x73;herpa-onnx 引擎 Apache-2.0；流式 Zipformer 中文模型 Apache-2.0；可选 SenseVoice 二次增强代码 MIT、模型权重可商用需保留署名

### 出问题怎么办



* 麦克风没反应 → 提示用户检查浏览器权限和系统麦克风权限

* 识别不准 → 用户手动修正，后续可选开启 Two-Pass 用 SenseVoice 二次校准提升准确率

* 模型加载慢 → 首次加载显示 loading，加载完后缓存，以后秒开

### 花多少钱

0 元。纯前端本地推理，不耗服务器资源，不收用户钱，也不花第三方 API 费。

**关键实现点：**



* 模型路径：`public/models/` 下放置 sherpa-onnx-streaming-zipformer-zh 系列 int8 量化模型

* Hook：封装 `useSpeechInput`，暴露 `start()` / `stop()` / `transcript` / `isListening`

* UI：AntD Input 的 `suffix` 或 TextArea 的 `footer` 挂麦克风图标按钮

* VAD：silero\_vad.onnx 自动分段，静音后自动结束

* 接入范围：先扫项目内所有 `Input` / `TextArea` 列清单，确认后统一包装
