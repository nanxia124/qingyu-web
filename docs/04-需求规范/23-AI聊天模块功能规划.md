# AI 聊天模块功能规划

### 这是什么

现在聊天页（点顶部"对话"进去那个页面）还是个空壳子：你发一句话，它 0.4 秒后回你一句固定的"服务待开通"，刷新一下你刚打的字就全没了。这份文档把"要把它做成一个真正能用的 AI 聊天工具"需要做的所有功能列清楚，一共九大类，每条标了优先级——P0 是必须先做、不做就没法上线的；P1 是做了体验明显变好的；P2 是远期优化。

### 用户怎么用

1. 打开聊天页，左边是你之前聊过的所有对话列表，右边是当前对话的消息

2. 底部输入框打字，Enter 发送，AI 一个字一个字往外蹦（不是等半天一次性出来）

3. 聊完关掉页面，下次打开还能接着上次的聊，不会丢

4. 想把 AI 画的图、写的东西存下来，一键存到你的资产库里

5. 不想被打扰的时候开免打扰，凌晨不会响提示音

6. 想把聊天记录导出备份，或者换手机了导回来，都能弄

### 现在长什么样

还没开始做真正的聊天。现在页面上有的东西：右上角能选模型（跟生图页用的是同一套模型列表）、输入框能自动变高、有个麦克风按钮能语音输入、AI 回复下面有个复制按钮、发送的时候有个"思考中"的脉冲动画。

但底下是空的：消息只存在浏览器内存里，刷新就没；没有历史对话列表；没有新建/删除/重命名对话；没有接真正的 AI 后端；回复是写死的"服务待开通"；不是流式的（字不会一个一个蹦）；不支持 Markdown 排版（AI 回的表格、代码块、加粗现在都显示不出来）；没有多轮上下文（你问它第二句它根本不记得第一句说了啥）。

### 业务规则

#### 第零组：聊天基本能力（前置，P0）

这组不在最初清单里，但不做这些，后面九大类功能全是空谈。

1. **<span style="font-size:18px;color:#fff">你发的每一句话和 AI 回的每一句话，都存在你账号下面，关掉浏览器、换台电脑登录，记录都还在。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">对话表 conversations（id, user_id, title, created_at, updated_at），消息表 messages（id, conversation_id, role, content, created_at），通过 /api/chat/conversations 和 /api/chat/messages CRUD，前端用 zustand store + react-query 缓存</span>

2. **<span style="font-size:18px;color:#fff">左边有一条对话列表，能新建对话、删对话、改对话名字。点哪条就打开哪条。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">左侧边栏 ConversationList 组件，按 updated_at 倒序，每条显示标题（取用户第一条消息前 20 字）+ 相对时间，悬停显示删除/重命名按钮，删除走二次确认弹窗</span>

3. **<span style="font-size:18px;color:#fff">AI 回复是一个字一个字蹦出来的，不是等半天一次性出来。你想打断就点停止。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">后端 SSE（Server-Sent Events）流式转发上游 LLM 接口的 chunk，前端 fetch ReadableStream 逐段 append 到当前 assistant 消息，停止按钮 abort controller 中断请求</span>

4. **<span style="font-size:18px;color:#fff">你问第二句的时候，AI 记得你第一句说了什么，不用你每次重复背景。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">每次请求带上当前 conversation 最近 N 条消息作为 context window（默认 20 轮），超长时按 token 数截断旧消息，system prompt 单独放在最前面</span>

5. **<span style="font-size:18px;color:#fff">AI 回的东西能正常显示：加粗、表格、代码块、列表都排好版，代码块能一键复制。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">用项目已装的 streamdown 渲染 Markdown，代码块用 @uiw/react-codemirror 高亮，代码块右上角放复制按钮</span>


#### 第一组：消息操作

6. **<span style="font-size:18px;color:#fff">你可以把某一条消息转发给另一个对话，或者转发给朋友（复制链接/导出图片）。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">P1 聊天专属。消息 hover 出现"转发"按钮，可选"转发到新对话"（把这条消息作为新对话第一条 user 消息）或"复制为图片"（html-to-image 把气泡渲染成 PNG 下载）</span>

7. **<span style="font-size:18px;color:#fff">你可以把某条消息标成未读，下次进来提醒你还没看。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">P2 聊天专属。messages 表加 is_unread 字段，前端在未读消息上方插入一条细分隔线"以下未读"，点已读后清除。个人聊天场景使用率低，远期再做</span>

8. **<span style="font-size:18px;color:#fff">你可以批量勾选多条消息一起删，不用一条一条点。删之前会弹确认框。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">P1 聊天专属。消息列表进入多选模式（长按或右上角多选按钮），每条消息前面出现勾选框，底部出现"删除 N 条"按钮，删除前 antd Modal.confirm 二次确认，成功后 message.success 提示</span>

9. **<span style="font-size:18px;color:#fff">你在聊天区往下滑（或者按住某条消息），能看到这条消息的精确时间：几点几分几秒发的。平时只显示"刚刚""5 分钟前"。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">P2 聊天专属。平时 meta 行显示相对时间（dayjs fromNow），hover 或上滑手势时 title tooltip 显示完整 YYYY-MM-DD HH:mm:ss，不额外占布局空间</span>


#### 第二组：输入框增强

10. **<span style="font-size:18px;color:#fff">输入框旁边有个笑脸按钮，点开能选表情，点一下就插进去。</span>**<br>
    <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">P1 聊天专属。用 emoji-picker-react 或 antd 自定义面板，分类 Tab（常用/笑脸/手势/动物），选中后在光标位置插入 unicode emoji，不引入图片表情以减少体积</span>

11. **<span style="font-size:18px;color:#fff">输入框里打一个斜杠 /，会弹出快捷指令菜单，比如 /写周报、/翻译、/总结，选了之后自动填上对应的提示词模板。</span>**<br>
    <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">P1 聊天专属。监听 input 里的 / 触发 SlashCommandMenu，内置一批常用指令模板（总结、翻译、润色、代码解释、列大纲），用户也能在设置里自定义，选中后把模板文字填进输入框光标处</span>

12. **<span style="font-size:18px;color:#fff">输入框记住你这次会话里发过的所有句子，按上箭头能往上翻历史输入，不用重新打。</span>**<br>
    <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">P2 聊天专属。本地 localStorage 存当前 conversation 的输入历史（最近 50 条），光标在空输入框时按 ArrowUp 调出上一条，ArrowDown 往下翻，Esc 关闭。不跨设备同步</span>

13. **<span style="font-size:18px;color:#fff">输入框能一键插入常用代码片段（比如一段 Python 模板、正则表达式），不用每次重新写。</span>**<br>
    <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">P2 聊天专属。斜杠指令下的子分类，代码片段存在用户设置里，支持命名和变量占位符 {{file}}，插入后自动高亮占位符让用户填。远期看用户实际需求再定</span>


#### 第三组：通知提醒

14. **<span style="font-size:18px;color:#fff">AI 回完你的话会"叮"一声，你能在设置里选三种声音：叮咚、水滴、静音。</span>**<br>
    <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">P1 全站级。Web Audio API 播放内置短音效（public/sounds/ 下 3 个 ogg），设置项存 user 表 notification_sound 字段，0=静音 1=叮咚 2=水滴，浏览器自动播放策略要求用户先交互过页面才允许发声</span>

15. **<span style="font-size:18px;color:#fff">浏览器标签页上能看到有几条未读消息的小红点，不用切回去看就知道有人回你了。</span>**<br>
    <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">P2 全站级。Document.title 动态改成 "(3) 轻域"，配合 favicon 加角标（动态生成 canvas 图标替换），页面切回前台时清除。纯前端，不依赖推送服务</span>

16. **<span style="font-size:18px;color:#fff">你可以设置免打扰时间段（比如晚上 11 点到早上 8 点），这段时间内不响提示音、不弹通知。</span>**<br>
    <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">P1 全站级。设置里 dnd_start / dnd_end 两个字段存 "HH:mm"，收到通知时用 dayjs 判断当前时间是否落在区间内（支持跨午夜），落在区间内只静默更新角标不发声</span>

17. **<span style="font-size:18px;color:#fff">你离开网站很久没回来，AI 已经回了的话，能给你发邮件或者微信提醒你回来看。</span>**<br>
    <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">P2 全站级。后端定时任务每 15 分钟扫一次：用户最后在线时间 > 30 分钟、且有未读 assistant 消息，发一封摘要邮件（用现有邮件服务）。微信推送需要接企业微信/微信公众号模板消息，涉及微信审核，远期</span>


#### 第四组：无障碍

18. **<span style="font-size:18px;color:#fff">全程不用鼠标也能聊：Tab 键在按钮和输入框之间跳，Enter 发送，方向键选历史消息，Esc 关掉弹窗。</span>**<br>
    <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">P1 全站级。所有可交互元素加 aria-label，键盘焦点可见（focus-visible 样式），侧边栏对话列表支持上下方向键选择+Enter 打开，消息区滚动不抢焦点，遵循 WAI-ARIA chat pattern</span>

19. **<span style="font-size:18px;color:#fff">如果你系统里开了"减少动画"偏好，网站就把所有过渡动画、脉冲、粒子效果关掉，直接切换。</span>**<br>
    <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">P1 全站级。matchMedia('(prefers-reduced-motion: reduce)') 监听，命中时给根 html 加 class reduce-motion，CSS 里 * { animation: none !important; transition: none !important }，"思考中"脉冲直接换成静态转圈</span>


#### 第五组：性能优化

20. **<span style="font-size:18px;color:#fff">哪怕你跟 AI 聊了几百上千条消息，滚动也不卡，不会越聊越慢。</span>**<br>
    <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">P1 聊天专属。用项目已装的 react-window 做 FixedSizeList 或 VariableSizeList 虚拟滚动，只渲染可视区 ±5 屏的消息，消息高度预估 + 动态测量修正。注意：Markdown 渲染和代码块高度不一，用 VariableSizeList 配合 measure</span>

21. **<span style="font-size:18px;color:#fff">聊天里发的图片（AI 画的、你贴的），只有滑到屏幕附近才开始加载，不会一打开就把几百张图全下下来。</span>**<br>
    <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">P1 聊天专属。img 标签 loading="lazy" + IntersectionObserver 包裹，先显示低分辨率占位图（模糊的 16px 缩略图），进入视口后再加载原图。配合虚拟滚动，卸载的图片同时释放 blob URL</span>

22. **<span style="font-size:18px;color:#fff">聊了很久以后，很早以前的消息会从内存里清掉，不会让浏览器越占越卡。</span>**<br>
    <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">P2 聊天专属。内存里只保留最近 100 条消息的完整对象，更早的消息只在滚到顶部时按需从后端分页拉取（cursor-based pagination），离开对话时清空当前 conversation 的 store 数据。不影响持久化，只清内存</span>


#### 第六组：跨页联动

23. **<span style="font-size:18px;color:#fff">在聊天里让 AI 画了一张图，点一下"发到画布"，这张图就出现在你的画布里，可以继续改。</span>**<br>
    <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">P1 聊天专属。AI 生成图片消息下方出现"发送到画布"按钮，调用 canvas store 的 addLayerFromImage(url)，跳转到 /canvas?layer=<assetId>，画布那边自动加一个图片图层</span>

24. **<span style="font-size:18px;color:#fff">AI 帮你写的文案、画的图、生成的代码，自动存到你的资产库里，不用你手动另存。</span>**<br>
    <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">P1 聊天专属。assistant 消息里检测到图片 URL 或代码块，自动调 /api/assets 创建资产记录（type=image/code/text, source=chat, conversation_id），用户在 /favorites 或资产页能看到，可关闭自动存储改为手动保存</span>

25. **<span style="font-size:18px;color:#fff">下次打开网站，自动把你上次聊到一半的对话打开，不用你再从列表里翻。</span>**<br>
    <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">P0 聊天专属。用户表存 last_open_conversation_id，登录跳转 /chat 时自动带上该 conversation_id 打开对应对话；该对话已被删则回退到新建对话页。配合第零组的对话列表一起做</span>


#### 第七组：多端适配

26. **<span style="font-size:18px;color:#fff">手机上打开聊天页，输入框、消息列表、对话列表都要排得舒服，不会挤成一团或者需要横屏才能看。</span>**<br>
    <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">P1 聊天专属。响应式断点：<768px 时左侧对话列表收成抽屉（汉堡按钮呼出），消息区 max-width 从 820px 放到全宽，用户气泡最大宽度从 520px 放到 85%，输入框圆角从 rounded-full 改成 rounded-2xl 适配触屏</span>

27. **<span style="font-size:18px;color:#fff">平板上横屏用的时候，左边对话列表和右边聊天同时显示，不用来回切。</span>**<br>
    <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">P2 全站级。768px~1280px 区间采用两栏布局：左侧固定 280px 对话列表 + 右侧聊天区，>=1280px 再加右侧上下文面板。用 CSS Grid 或 flex 自适应，不需要单独做一套平板 UI</span>

28. **<span style="font-size:18px;color:#fff">以后可能会出 Windows/Mac 桌面客户端，聊天功能在客户端里跟网页版一模一样，还能拖出独立窗口。</span>**<br>
    <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">P2 全站级。技术选型 Tauri 或 Electron，先保证网页版功能完整再套壳。此条仅记录方向，不在本阶段排期</span>


#### 第八组：数据安全

29. **<span style="font-size:18px;color:#fff">你发的话和 AI 回的话，在你自己设备上加密了才传到服务器，服务器上存的也是密文，我们自己都看不到内容。</span>**<br>
    <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">P2 聊天专属。端到端加密（E2EE）：用 Web Crypto API 生成用户密钥对，公钥上传服务器，私钥用用户密码派生（PBKDF2/Argon2）后只存本地。消息用接收方公钥加密。注意：这会导致服务端无法做敏感词过滤（跟第 31 条冲突），需要权衡或只对私密对话开启</span>

30. **<span style="font-size:18px;color:#fff">你点"删除账号"的时候，你所有的聊天记录、对话、资产，连同数据库里的备份，30 天内彻底删掉，谁都找不回来。</span>**<br>
    <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">P0 全站级。GDPR/个保法合规。账号删除走软删除标记 + 30 天冷静期 + 定时任务硬删除，级联删除 conversations、messages、assets、billing 记录，对象存储里的文件也一并清。已有 /account/security 页面，需补聊天数据的级联清理</span>

31. **<span style="font-size:18px;color:#fff">你可以把自己的所有聊天记录导出成一个文件（JSON 或 Markdown），也能把以前导出的文件导回来恢复。</span>**<br>
    <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">P1 全站级。导出：后端打包用户所有 conversations + messages 成 zip（JSON 结构化 + Markdown 可读版各一份），通过 file-saver 下载。导入：上传 zip 后端校验格式后批量插入，重复 conversation_id 时追加新消息不覆盖</span>


#### 第九组：运营管理

32. **<span style="font-size:18px;color:#fff">你发的话如果包含违法违规内容（比如教人造武器、色情），系统会拦下来不让发，并提示你。</span>**<br>
    <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">P0 后端。用户消息发出后先过一层内容审核（可用第三方内容安全 API 或自建敏感词库 + 大模型审核），命中则不调用上游 LLM，直接返回"您的消息包含违规内容，已被拦截"，并写审计日志到 admin 后台</span>

33. **<span style="font-size:18px;color:#fff">如果有人反复发违规内容，管理员能在后台把他的聊天功能封掉，封禁期间他发消息会提示"账号已被限制"。</span>**<br>
    <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">P0 后端。用户表加 chat_banned_until 字段 + ban_reason，admin 后台已有 AdminUsersPage 加"封禁聊天"操作，后端 /api/chat/send 前置检查 banned_until，未解封则返回 403。封禁记录进 AdminAuditsPage</span>

34. **<span style="font-size:18px;color:#fff">一个用户一分钟内不能发太多条消息（比如超过 20 条），防止有人用脚本刷接口烧钱。</span>**<br>
    <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">P0 后端。/api/chat/send 接口限流：按 user_id 滑窗计数，1 分钟 > 20 条返回 429，单日累计 > 500 条触发风控告警。结合现有计费额度体系（daily_usage_reservations），超额时前端按钮禁用 + 后端拒绝双保险</span>


### 出问题怎么办

* AI 不回复 / 一直转圈 → 先检查模型选择器选的模型是不是在线，再看网络请求是不是被限流（429）或违规拦截（403），最后看后端 SSE 连接是不是断了
* 刷新后聊天记录没了 → 确认第零组的消息持久化有没有接上，如果还在 P0 开发期这是已知问题
* 手机上输入框被键盘挡住 → 检查 viewport 高度计算，移动端用 visualViewport API 动态调整 padding-bottom
* 导出的文件导不回来 → 提示文件格式不对，只接受系统自己导出的 zip，不接受手改后的文件
* 被误封了聊天 → 后台申诉入口，管理员在 AdminAuditsPage 里能看到封禁原因并手动解封

### 花多少钱

- **P0 基本能力**：主要是后端开发成本，上游 LLM 调用按 token 计费（走现有计费体系），服务器多存一份对话数据，存储成本几乎为零
- **P1 体验优化**：提示音、表情、键盘导航这些纯前端不花钱；邮件推送每封约 0.0005 元；敏感词审核按调用量计费（第三方内容安全 API 约 1.5 元/千次）
- **P2 远期**：端到端加密不额外花钱但开发量大；桌面客户端需要单独维护构建发布流水线；微信推送需要企业认证（300 元/年认证费）
