### 后续必须达到的要求

9. **<span style="font-size:18px;color:#fff">服务器登录凭据不能放进共享代码。换凭据时先确认新的能用，再撤销旧的；只删除当前文件不能消除过去记录里的风险。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">本地已完成：.gitignore 忽略 github_actions_deploy，git rm --cached 停止跟踪，本地文件保留。历史提交仍含旧私钥，未轮换 SSH 或对应 Secrets、未撤销服务器授权。两个本地公钥文件指纹不同，只证明它们不是同一公钥，不证明旧授权失效。历史清理须单独制定方案并协调已有克隆，不擅自重写历史或强推；不得记录私钥正文。</span>



10. **<span style="font-size:18px;color:#fff">网站目录只能放给访客看的网页和资源，服务器设置单独存放。过去误放进去的文件也要核对并清理。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">本地已完成：deploy.yml 按 run_id/run_attempt 分隔暂存目录，frontend 与 config 分开上传，只复制 frontend 到站点目录；Nginx 增加敏感文件拒绝规则。隔离容器中的 HTTP/HTTPS 实测证明，即使文件真实存在也返回 404，普通网页、脚本和证书验证路径仍返回 200。生产没有发布或清理；部署新规则不会自动删除旧文件，语音及 OAuth 仍需对应部署后的业务验收。</span>



11. **<span style="font-size:18px;color:#fff">只供服务器内部使用的服务不能直接接收外部连接。收紧后，正常登录、生成图片和实时更新仍要可用。</span>**<br>

13. **<span style="font-size:18px;color:#fff">进入管理功能必须明确确认管理员身份，连续猜密码要被限制。加强密码保护时，现有管理员仍要能正常登录或完成受控重置。</span>**<br>

#### 第一批：堵住现在正在漏的

19. **<span style="font-size:18px;color:#fff">把最新后端代码部署到生产，先让渠道名和渠道 UUID 不再公开返回。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">本地 postgres-billing-store.mjs 的 listPublicModelCatalogChannels() 已改为查 app.model_catalog 表，只返回目录 ID、显示名、能力和协议占位地址，不返回 platform_api_keys.id（渠道 UUID）或 platform_api_keys.name（渠道名）。生产仍在跑旧版直接 SELECT 渠道表。部署最新 api-server.mjs + postgres-billing-store.mjs 后此问题即消失。</span>



20. **<span style="font-size:18px;color:#fff">别人的网页不能偷偷读我们后端的数据。不是我们自己网站的请求，后端干脆不回"允许跨域"这句话。</span>**<br>
   <span style="display:inline-block;font-size:12px;color:#666;transform:scale(0.35);transform-origin:left top;line-height:1">api-server.mjs 的 requestCorsHeaders() 对白名单外 Origin 兜底返回 Access-Control-Allow-Origin: *，sendJSON() 两处也有兜底 *。改为白名单不命中时不返回任何 CORS 头（空对象）；同源请求与 curl 不受影响；保留 CONFIGURED_CORS_ORIGINS 白名单与同源 host 校验逻辑。</span>



21. **<span style="font-size:18px;color:#fff">告诉浏览器别把我们网站嵌到别人网页里、别猜文件类型、别随便跳转。这些规矩在 nginx 上加。</span>**<br>
